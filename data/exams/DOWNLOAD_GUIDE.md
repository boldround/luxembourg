# Q-Net 세무사 2차 기출문제 — 수동 다운로드 가이드

> **자동 다운로드 불가 판정.**
> Q-Net 자료실은 게시물 목록과 첨부파일 링크가 모두 JavaScript로 동적 렌더링되며, 정적 HTML에는 다운로드 URL이 노출되지 않는다. 또한 첨부파일은 세션/CSRF 토큰을 요구할 가능성이 높아 무리하게 시도하면 IP가 차단된다.
> **노아가 직접 브라우저에서 받는 것이 가장 빠르고 안전하다.**

받을 대상: **최근 5년치 (2020~2024) 세무사 2차 시험 기출문제**, 과목 4개씩 = **총 20개 파일**

---

## 1. 사전 준비

저장 폴더는 이미 만들어져 있다.

```
/Users/noah/workspace/luxembourg/data/exams/raw/
  2020/
  2021/
  2022/
  2023/
  2024/
```

브라우저(Safari/Chrome) 다운로드 기본 경로를 잠시 위 폴더로 바꾸거나, 받은 후에 직접 옮긴다.

---

## 2. 다운로드 절차 (연도별 반복)

### Step 1 — 자료실 접속

1. 다음 URL을 브라우저에 붙여넣고 접속한다.
   - **기출문제 내려받기**: <https://www.q-net.or.kr/cst003.do?id=cst00309&gSite=L&gId=22>

2. 페이지가 열리면 검색 영역에서 다음을 설정한다.
   - **종목명**: `세무사`
   - 검색 버튼 클릭

### Step 2 — 회차 선택

세무사 2차 시험의 최근 5년 회차는 다음과 같다 (회차는 시험연도 기준).

| 시행연도 | 회차 (참고) | 시험일 (참고) |
|---|---|---|
| 2024 | 제61회 | 2024-08-31 |
| 2023 | 제60회 | 2023-08-26 |
| 2022 | 제59회 | 2022-08-27 |
| 2021 | 제58회 | 2021-08-28 |
| 2020 | 제57회 | 2020-10-24 |

> 회차 번호는 Q-Net 게시물 제목과 다를 수 있다. 게시물 제목에 **연도 + "2차"** 가 들어간 항목을 찾으면 된다.

### Step 3 — 게시물 진입 → 첨부파일 다운로드

해당 연도 게시물(예: `2024년도 제61회 세무사 제2차 시험문제`)을 클릭하면 상세 페이지로 이동한다. 페이지 하단에 첨부파일 4개가 있다.

각 게시물마다 **4개 과목** 파일을 모두 받는다.

1. `회계학 1부` (.hwp 또는 .hwpx)
2. `회계학 2부`
3. `세법학 1부`
4. `세법학 2부`

> 일부 연도는 4개 과목이 한 파일(zip 또는 통합 hwp)에 묶여 있을 수 있다. 그런 경우 받은 후 압축을 풀어 4개로 분리한다.

### Step 4 — 파일명 변경 후 폴더로 이동

받은 파일은 다음 컨벤션으로 이름을 바꿔서 해당 연도 폴더에 넣는다 (파서가 자동 인식).

```
{연도}-2차-{과목}.{확장자}
```

예시:

```
/Users/noah/workspace/luxembourg/data/exams/raw/2024/
  2024-2차-회계학1부.hwpx
  2024-2차-회계학2부.hwpx
  2024-2차-세법학1부.hwpx
  2024-2차-세법학2부.hwpx
```

> Q-Net 원본 파일명을 그대로 두어도 파서가 대부분 인식하지만, 위 형식으로 통일하면 디버깅이 쉽다.

### Step 5 — 5개 연도(2020~2024) 반복

Step 1~4를 5번 반복하면 끝. **최종적으로 총 20개 파일**이 `raw/{년도}/` 아래에 모인다.

## 3. 정답 파일도 함께 받기 (선택, 권장)

문제만으로는 풀이 자동 생성이 검증되지 않는다. 동일 절차로 정답 PDF/HWP도 받기.

- **최종정답 자료실**: <https://www.q-net.or.kr/cst003.do?id=cst00310&gSite=L&gId=22>

저장 위치 (별도 폴더 권장):

```
/Users/noah/workspace/luxembourg/data/exams/raw/{연도}/answers/
  2024-2차-회계학1부-정답.pdf
  ...
```

---

## 4. 다운로드 완료 후 다음 단계

20개 파일이 모이면 토토에게 알려줘. 그러면 자동으로:

1. **파싱 실행**
   ```bash
   cd /Users/noah/workspace/luxembourg
   python3 -m src.collectors.hwpx_parser --type 2차
   ```
2. 파싱 결과 검증 (`data/exams/{과목}/{연도}.md` 5개씩 × 4과목 = 20개 생성 확인)
3. 풀이 자동 생성 파이프라인 가동

> HWP(.hwp) 파일이 섞여 있으면 `pip install pyhwp` 가 필요하다 (`hwp5html` CLI). HWPX(.hwpx)는 표준 라이브러리만으로 파싱된다.

---

## 5. 트러블슈팅

| 증상 | 대응 |
|---|---|
| 게시물 검색이 안 된다 | 검색어를 `세무사`만으로 좁히고, 정렬을 "최신순"으로 |
| 첨부파일 클릭해도 받아지지 않는다 | 팝업 차단 해제, Q-Net 로그인이 필요한 경우 있음 |
| HWP가 미리보기만 되고 다운로드가 안 된다 | 우측 상단 "다운로드" 버튼 또는 마우스 우클릭 → 다른 이름으로 저장 |
| 정답이 게시물에 없다 | 위 4번의 "최종정답" 자료실에서 별도로 받기 |
| 파일명이 한글 깨짐 | macOS Finder에서 직접 이름 바꾸기 (Step 4 컨벤션 적용) |

---

## 6. 자동 다운로드를 시도하지 않은 이유

- Q-Net의 첨부파일 다운로드는 **세션 토큰 + JS 렌더링** 기반으로, 정적 HTML에서 파일 URL을 추출할 수 없다.
- 헤드리스 브라우저로 우회하더라도 한국산업인력공단은 자동화 트래픽에 민감하며, **403/429 차단 시 노아의 IP가 일정 시간(또는 영구) 차단**되어 수동 접근까지 막힐 수 있다.
- 노아의 글로벌 메모리 (`feedback_crawling_safety.md`): "IP 차단 방지: 5초+ 대기, 대량시 10초+1분 휴식, 차단 즉시 중단" 원칙에 따라 **선제적으로 시도 자체를 중단**했다.
