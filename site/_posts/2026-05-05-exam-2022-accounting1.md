본 회차는 회계학 1부의 빈출 핵심 쟁점을 고르게 다루었다. 문제 1·2는 재무회계 종합문항(재고자산, 지분법, 통화선도, 차입원가 자본화, 후속사건, 현금흐름표 직접법·간접법, 회계정책 변경/추정변경/오류수정), 문제 3·4는 원가관리회계(제약자원하 최적조합, 대체가격, 특별주문, 매출조업도/변동예산차이, 표준원가, BEP, 직접재료 구입예산)로 구성되었다. 난이도는 평이∼중상 수준이며, **차입원가 자본화의 일시투자수익 차감 처리**, **지분법 하향거래 미실현이익의 정률법 실현**, **현금흐름표의 사채할인발행차금 상각 분리**가 변별 포인트였다.

## [문제 1] 재무회계 종합 (30점)

### 물음 1) 재고자산 (10점)

#### (1) 20×1년 1월 2일 매입 상품의 취득원가

장기연불조건 매입이므로 미래지급액은 현재가치로 평가한다. 운반비는 (주)한국이 부담했으므로 (주)세무의 취득원가에 포함하지 않는다.

- 즉시 지급 현금: ₩500,000
- 2년 후 지급액의 현재가치: $2{,}000{,}000 \times 0.8417 = ₩1{,}683{,}400$

**취득원가 = 500,000 + 1,683,400 = ₩2,183,400**

#### (2) 20×1년 8월 20일 매입 상품의 취득원가

선지급금(US$700)은 비화폐성 자산이므로 **선지급일 환율**을 그대로 자산 취득원가에 사용한다. 입고시점에 인식하는 매입금액(현금지급분 + 미지급금)은 **입고일 환율**(₩1,350/US$)로 환산한다.

| 구분 | 금액(US$) | 적용환율 | 원화 |
|---|---:|---:|---:|
| 선지급금(6/30) | 700 | ₩1,150 | ₩805,000 |
| 입고일 현금지급(8/20) | 1,200 | ₩1,350 | ₩1,620,000 |
| 미지급금(8/20 인식) | 800 | ₩1,350 | ₩1,080,000 |
| **합계** | **2,700** | | **₩3,505,000** |

**취득원가 = ₩3,505,000**

#### (3) 감모 없을 때 20×1년 말 상품 재고수량

선적조건 판단:
- 12/25 매입(도착지 인도, 운송 중): 매수자(세무) 재고 아님 → 제외
- 12/28 판매(도착지 인도, 운송 중): 매도자(세무) 재고 유지 → 포함

$$1{,}000 + 2{,}500 + 2{,}600 - 4{,}100 = 2{,}000\text{개}$$

**재고수량 = 2,000개** (창고 외 운송 중인 출고 300개 포함)

#### (4) 창고 보관 실제 상품 재고수량

원가성 감모 150개 = 총감모의 75% → 총감모 = 200개, 원가성 없는 감모 = 50개.

- 실제 보유 수량 = 2,000 − 200 = 1,800개
- 그중 운송 중 출고 = 300개

**창고 보관 실제 재고 = 1,800 − 300 = 1,500개**

#### (5) 매출원가에 반영될 상품평가손실(환입)

순실현가능가치(NRV) = 1,300 − 40 = ₩1,260, 단가 ₩1,280 > NRV → 평가손실 인식.

- 단위당 평가손실: 1,280 − 1,260 = ₩20
- 기말 평가충당금: 1,800개 × 20 = ₩36,000
- 기초 평가충당금: ₩15,000
- 변동: 36,000 − 15,000 = **₩21,000 증가**

**매출원가 ₩21,000 증가**

### 물음 2) 지분법 (6점)

#### (1) 20×1년 지분법손익

(주)대한 20×1년 당기순이익 추정: 100,000 − 75,000 + 60,000(중간배당) = ₩85,000

미실현이익(하향, 세무→대한 재고): 120,000 × (20/120) = ₩20,000 → 20% 지분 부담 시 ₩4,000

$$\text{지분법손익} = 85{,}000 \times 20\% - 4{,}000 = 17{,}000 - 4{,}000 = ₩13{,}000$$

**지분법이익 ₩13,000**

#### (2) 지분법이익 ₩10,000일 때 (주)대한 주식 장부금액

- 취득원가: 1,200,000
- 지분법이익: +10,000
- 배당금 수령 차감: 60,000 × 20% = (12,000)

**장부금액 = 1,200,000 + 10,000 − 12,000 = ₩1,198,000**

#### (3) 20×2년 기계장치 미실현손익이 지분법손익에 미치는 영향

하향거래(세무→대한). 미실현이익 = 처분가 500,000 − 장부 400,000 = ₩100,000.
정률법(30%) 4개월(9/1~12/31) 실현률 = $30\% \times \tfrac{4}{12} = 10\%$

- 미실현이익 인식 차감: 100,000 × 20% = (20,000)
- 실현분 가산: 100,000 × 10% × 20% = +2,000
- 순영향 = (18,000)

**손실 ₩18,000**

### 물음 3) 통화선도 (4점)

매입(US$ 수취) 통화선도. 평가손익 = (선도환율 변동분) × 계약금액. 시간가치 무시.

#### ① 결산일(20×1.12.31)

선도환율 1,300 → 1,315, 매입 포지션이므로 상승 시 이익.

$$(1{,}315 - 1{,}300) \times 100 = ₩1{,}500\ \text{이익}$$

#### ② 만기일(20×2.3.31)

만기 청산이익 누적 = (1,350 − 1,300) × 100 = ₩5,000. 결산일까지 1,500 인식 완료 → 만기일 추가:

$$5{,}000 - 1{,}500 = ₩3{,}500\ \text{이익}$$

| 시점 | 손익 |
|---|---|
| 결산일 ① | **₩1,500 이익** |
| 만기일 ② | **₩3,500 이익** |

### 물음 4) 차입원가 자본화 (6점)

#### 20×1년

자본화기간: 20×1.4.1 ~ 20×1.12.31 (9개월)

평균지출액:
- 4/1: 600,000 × 9/12 = 450,000
- 10/1: 900,000 × 3/12 = 225,000
- 합계 = ₩675,000

**① 특정차입금 자본화차입원가**

$$800{,}000 \times 4\% \times \tfrac{9}{12} - 200{,}000 \times 3\% \times \tfrac{3}{12} = 24{,}000 - 1{,}500 = ₩22{,}500$$

**② 일반차입금 자본화이자율**

| 차입금 | 이자비용 | 가중평균 |
|---|---:|---:|
| BB 600,000 × 6% × 9/12 | 27,000 | 450,000 |
| CC 900,000 × 9% × 3/12 | 20,250 | 225,000 |
| **합계** | **47,250** | **675,000** |

$$\text{자본화이자율} = \tfrac{47{,}250}{675{,}000} = 7.0\%$$

**③ 일반차입금 자본화차입원가**

특정차입금 충당분 = 800,000 × 9/12 − 200,000 × 3/12 = 550,000
일반차입금 부담 평균지출 = 675,000 − 550,000 = 125,000

$$125{,}000 \times 7.0\% = ₩8{,}750\ (\le 47{,}250\ \text{한도})$$

#### 20×2년

자본화기간: 20×2.1.1 ~ 20×2.12.31 (12개월)

평균지출액(전기 자본화차입원가 미고려):
- 이월 1,500,000 × 12/12 = 1,500,000
- 1/1 300,000 × 12/12 = 300,000
- 10/1 1,200,000 × 3/12 = 300,000
- 합계 = ₩2,100,000

**④ 특정차입금 자본화차입원가**

$$800{,}000 \times 4\% \times \tfrac{12}{12} = ₩32{,}000$$

**⑤ 일반차입금 자본화이자율**

| 차입금 | 자본화기간 사용 | 이자비용 | 가중평균 |
|---|---|---:|---:|
| BB 600,000 × 6% | 1/1~6/30 (6개월) | 18,000 | 300,000 |
| CC 900,000 × 9% | 1/1~4/30 (4개월) | 27,000 | 300,000 |
| **합계** | | **45,000** | **600,000** |

$$\text{자본화이자율} = \tfrac{45{,}000}{600{,}000} = 7.5\%$$

**⑥ 일반차입금 자본화차입원가**

일반차입금 부담 평균지출 = 2,100,000 − 800,000 = 1,300,000
계산값 1,300,000 × 7.5% = 97,500 > 한도 45,000 → **한도 적용**

$$\text{자본화액} = ₩45{,}000$$

| 구분 | 금액 |
|---|---:|
| ① 20×1년 특정차입금 자본화 | ₩22,500 |
| ② 20×1년 일반차입금 자본화이자율 | 7.0% |
| ③ 20×1년 일반차입금 자본화 | ₩8,750 |
| ④ 20×2년 특정차입금 자본화 | ₩32,000 |
| ⑤ 20×2년 일반차입금 자본화이자율 | 7.5% |
| ⑥ 20×2년 일반차입금 자본화 | ₩45,000 |

### 물음 2) 회계정책 변경 허용 사유 (2점)

### 물음 3) 회계변경 (8점)

#### (1) 원가모형 → 재평가모형 (정책 변경, 전진법)

K-IFRS 1016 적용상 재평가모형 최초 채택은 1008의 소급적용 예외로, 비교공시는 **원가모형 그대로** 표시한다.

20×1년 말(원가모형): 감가상각누계액 = 50,000, 유형자산(총액) = 500,000.
20×2년 말(재평가모형): 재평가 전 장부금액 = 500,000 − 100,000 = 400,000, 공정가치 480,000. 비례수정법 적용.

비례계수 = 480,000 / 400,000 = 1.2
- 총장부금액 = 500,000 × 1.2 = ₩600,000
- 감가상각누계액 = 100,000 × 1.2 = ₩120,000

| 과목 | 20×2년 | 20×1년 |
|---|---:|---:|
| 유형자산(총액) | 600,000 | **① ₩500,000** |
| 감가상각누계액 | **② ₩120,000** | 50,000 |

#### (2) 정액법 → 연수합계법, 잔존내용연수 8년 (추정 변경, 전진법)

20×1년 말 장부 = 450,000.
20×2년 합계 = 8+7+...+1 = 36, 감가상각비 = 450,000 × 8/36 = ₩100,000.
20×2년 말 장부(순액) = 450,000 − 100,000 = ₩350,000.

| 과목 | 20×2년 | 20×1년 |
|---|---:|---:|
| 유형자산(순액) | **① ₩350,000** | 450,000 |
| 감가상각비 | 100,000 | **② ₩50,000** |

### 물음 4) 오류수정 (6점)

#### 오류 1: 차입원가 미자본화 + 취득세 비용처리

자본화 누락 120,000(20×1년 80,000, 20×2년 40,000) + 취득세 50,000(20×3년 초). 건물 가산액 합 = 170,000, 내용연수 20년 → 연 감가상각비 = 8,500.

**② 20×3년 당기순이익**: 일반관리비 50,000 자산화(+50,000) − 추가 감가상각비 8,500 = **+₩41,500**

**③ 20×3년 기초이익잉여금**: 20×2년 말까지 누적 효과 = 5,000 과대(20×2말 재고 5,000 과대만 잔존) → 수정 = **−₩5,000**

**④ 20×3년 당기순이익**: 기초재고 5,000 과대 효과 (+5,000) + 기말재고 6,000 과소 (+6,000) = **+₩11,000**

## [문제 3] 부품사업부 의사결정 (20점)

기본 데이터 정리:

| 항목 | S | D |
|---|---:|---:|
| 단위당 판가 | 500 | 800 |
| 단위당 변동원가 | 350 | 600 |
| 단위당 공헌이익 | 150 | 200 |
| 단위당 DL시간(=DL원가/400) | 0.2h | 0.4h |
| **DL시간당 공헌이익** | **750** | **500** |

총 DL시간 한도 14,000h, 시장수요 S 30,000개, D 25,000개.

### 물음 1) 최대 총공헌이익 (4점)

DL시간당 공헌이 큰 S 우선:
- S 30,000개 × 0.2 = 6,000h, 공헌 = 30,000 × 150 = 4,500,000
- 잔여 8,000h → D 8,000/0.4 = 20,000개, 공헌 = 20,000 × 200 = 4,000,000

**최대 총공헌이익 = ₩8,500,000**

### 물음 2) 부품 H 추가 시 최소 판매가격 (4점)

부품 H: 변동원가 = 130 + 200 + 140 = 470, DL시간 = 0.5h.

H 4,000개 추가 = 2,000h 필요 → 시간당 공헌이익이 가장 낮은 D를 대체.
H의 시간당 공헌 > D의 시간당 공헌(500)이어야 사업부 이익 증가:

$$\frac{P - 470}{0.5} > 500 \Rightarrow P > 720$$

**부품 H 단위당 판매가격은 ₩720을 초과해야 한다.**

### 물음 3) 부품 K 8,000단위 최소대체가격 (6점)

K = S와 동일 공정(0.2h) + DM 10원 추가 → 변동원가 360.
K 8,000개 = 1,600h 필요 → D 4,000개(=1,600/0.4) 감소.

K 1단위당 기회비용:
$$0.2\text{h} \times \tfrac{₩200}{0.4\text{h}} = ₩100$$

**최소대체가격 = 360 + 100 = ₩460**

(검증: 8,000 × 100 = 800,000 = D 4,000개 공헌이익 손실)

### 물음 4) 특별주문 (DL 17,000h 가정) (6점)

기존 수요 충족 시: S 30,000(6,000h) + D 25,000(10,000h) = 16,000h, 1,000h 여유.

특별주문 S 10,000개 = 2,000h 필요 → 1,000h는 여유분으로 충당, 1,000h는 D 2,500개 감소(=1,000/0.4)로 충당.

| 항목 | 금액 |
|---|---:|
| 특별주문 공헌이익 10,000 × (420 − 350) | +700,000 |
| D 2,500개 감소 공헌이익 손실 | (500,000) |
| **영업이익 증가** | **+₩200,000** |

**영업이익 ₩200,000 증가**

## [문제 4] 변동/전부원가, 표준원가, 종합예산 (20점)

### 물음 1) 매출조업도차이·변동예산차이 (4점)

예산 단위당 공헌이익 = 200 − 80(VM) − 50(V판관) = ₩70.

**① 매출조업도차이**
$$(4{,}200 - 4{,}500) \times 70 = -21{,}000$$
**₩21,000 불리**

**② 변동예산차이**

변동예산 공헌이익 = 4,200 × 70 = 294,000, 실제 공헌이익 = 378,000.

$$378{,}000 - 294{,}000 = +84{,}000$$
**₩84,000 유리**

### 물음 2) 변동원가 vs 전부원가 영업이익 차이 (4점)

**① 차이금액 = ₩0**

**② 이유**: 생산량과 판매량이 동일(재공품도 없음)하여 기초·기말 재고에 변동이 없으므로, 전부원가계산에서 제품에 배부되어 이연되는 고정제조간접원가가 존재하지 않는다. 즉 두 방법 모두 당기 발생 고정제조간접원가 전액을 당기비용으로 인식하기 때문이다.

### 물음 3) 표준원가 차이분석 (4점)

변동제조간접원가 표준배부율 = 단위당 V제조OH 15 / 단위당 표준DL시간 1h = ₩15/h.
표준시간(허용시간) = 4,200 × 1h = 4,200h.

**① 실제 직접노무시간**

능률차이: $(\text{실제} - 4{,}200) \times 15 = 1{,}500$ → 실제 − 4,200 = 100 → **실제시간 = 4,300시간**

**② 변동제조간접원가 실제 발생액**

소비차이: $\text{실제} - 4{,}300 \times 15 = 3{,}500$ → 실제 = 64,500 + 3,500 = **₩68,000**

### 물음 4) 제품 B 추가 시 고정원가 증가 (4점)

A:B = 7:3, 단위당 공헌이익 A=70, B=80.

세트당 공헌이익(A 7개 + B 3개) = 7×70 + 3×80 = ₩730.
A의 BEP 4,067 → 세트수 N = 4,067/7 = 581.
BEP에서 총공헌 = 730 × 581 = ₩424,130 = 총고정원가.

기존 고정원가 = 135,000 + 78,000 = ₩213,000.

**고정원가 증가 = 424,130 − 213,000 = ₩211,130**

### 물음 5) 직접재료 구입예산 (4점)

생산량(완성품 기준) = 판매량 4,500단위.
당기 착수량(DM 투입 기준) = 완성 + 기말재공 − 기초재공 = 4,500 + 100 − 150 = 4,450단위.

DM 사용량 = 4,450 × 2kg = **8,900kg**

DM 단가 = 단위당 DM 원가 40 / 단위당 수량 2kg = ₩20/kg.

기말 DM 재고 = 차기 판매량 4,500 × 10% × 2kg = 900kg.
기초 DM 재고 = 700kg.

DM 구입량 = 사용 + 기말 − 기초 = 8,900 + 900 − 700 = **9,100kg**

**직접재료 구입예산 = 9,100kg × ₩20 = ₩182,000**
