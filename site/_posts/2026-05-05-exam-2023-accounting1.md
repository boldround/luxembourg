본 회차는 회계학 1부 전 영역(재무·연결·원가관리)을 4문제·100점으로 폭넓게 출제하였다. 재무회계는 K-IFRS 제9호의 **계약변경**(자산/부채 양면)과 **사업모형 변경에 따른 재분류**, 전환사채 **부분전환·재매입** 등 빈출 + 까다로운 주제가 결합되었다. 연결은 상·하향 미실현 + 토지 즉시 실현 + 건물 추가 감가 + 배당 제거의 종합형. 원가관리는 결합원가 NRV법 + 전부·변동원가 차이, 그리고 제약자원·기회원가·정보의 가치 등 의사결정 핵심 논점이 모두 출제되었다. 계산 정확도와 시간배분이 합격 분기점이다.

## [문제 1] 금융상품 — 계약변경, 재분류, 전환사채 (30점)

### 물음 1) A사채 계약변경

#### (1) 20×2.12.31 계약변경 합의 전 (주)세무의 금융자산 장부금액

**1단계 — 발행시점 PV (유효이자율 10%)**
- 액면 1,000,000, 표시이자 6%(60,000), 만기 3년
- 발행가 = 1,000,000 × 0.7513 + 60,000 × 2.4868 = 751,300 + 149,208 = **900,508**

**2단계 — 매년 상각후원가**

| 일자 | 기초 BV | 유효이자(10%) | 표시이자 | 기말 BV |
|------|---------|---------------|----------|---------|
| 20×1.12.31 | 900,508 | 90,051 | 60,000 | 930,559 |
| 20×2.12.31 | 930,559 | 93,056 | 60,000 | 963,615 |

#### 정답
**계약변경 합의 전 장부금액 = 963,615원**

#### (2) 금융자산 제거조건 미충족 시 (주)세무의 계약변경이익(가정 BV 960,000)

K-IFRS 제9호 5.4.3: **변경된 현금흐름을 최초 유효이자율(10%)로 재할인한 PV** 와 변경 전 총장부금액의 차이를 손익으로 인식. 수령한 수수료는 변경 후 자산의 장부금액에서 조정하여 잔여기간에 걸쳐 상각한다(즉시 손익 효과 없음).

**1단계 — 변경 후 현금흐름의 PV (10%, 만기 3년·표시이자율 4%)**
- 1,000,000 × 0.7513 + 40,000 × 2.4868 = 751,300 + 99,472 = **850,772**

**2단계 — 계약변경손익**
- 850,772 − 960,000 = **−109,228**

#### 정답
**계약변경손실 = (−)109,228원**

#### (3) (주)한국이 인식할 계약변경이익 (금융부채)

K-IFRS 제9호 3.3.2 + B3.3.6: 새 조건 하의 현금흐름(수수료 포함)을 **기존 유효이자율(10%)** 로 할인한 PV가 기존 부채 PV의 10% 이상 차이가 나면 **실질적 변경** → 기존 부채 제거, 신규 부채는 **현행이자율(8%)** 로 측정. 발생한 수수료는 부채소멸손익에 포함(비용 처리).

**1단계 — 10% 테스트**
- 변경 후 PV(10%) + 지급수수료 = 850,772 + 12,000 = 862,772
- |862,772 − 960,000| / 960,000 = 10.13% > 10% → **실질적 변경**

**2단계 — 신규 부채 PV (8%, 만기 3년)**
- 1,000,000 × 0.7938 + 40,000 × 2.5771 = 793,800 + 103,084 = **896,884**

**3단계 — 부채소멸손익**
- 기존 BV − 신규 부채 PV − 지급수수료 = 960,000 − 896,884 − 12,000 = **51,116**

#### 정답
**계약변경이익 = 51,116원**

### 물음 2) B사채 — FVOCI → AC 재분류

#### (1) 재분류일

K-IFRS 제9호: **사업모형 변경 후 첫 보고기간의 첫 날**. 변경일 20×1.9.1 → 첫 보고기간 = 20×2년.

**재분류일 = 20×2년 1월 1일**

#### (2) 20×1년도 당기순이익 영향

20×1.9.1까지는 사업모형 변경 시점이고 **재분류일은 20×2.1.1이므로 20×1년 내내 FVOCI** 분류 유지. FVOCI 채무상품의 평가손익은 OCI, 이자수익(유효이자율법)과 손상차손은 PL이다.

**1단계 — 이자수익**
- 950,244 × 10% = **95,024**

**2단계 — 12개월 기대신용손실**
- 손상차손 = **30,000** (PL, OCI에서 동일 금액 가산하여 자산은 FV 그대로)

#### 정답
**20×1년 NI 영향 = 95,024 − 30,000 = +65,024원**

#### (3) 20×2년도 당기순이익 영향

재분류 시 FVOCI 누적평가손익을 자산에서 조정 → AC 장부금액은 **원래의 상각후원가**가 됨.

**1단계 — 20×1년말 상각후원가**
- 950,244 + (95,024 − 80,000) = **965,268**

**2단계 — 20×2년 이자수익 (재분류 후에도 최초 유효이자율 10% 적용)**
- 965,268 × 10% = **96,527**

**3단계 — 손실충당금 환입**
- 30,000 → 10,000, 환입 = **20,000** (PL 이익)

#### 정답
**20×2년 NI 영향 = 96,527 + 20,000 = +116,527원**

### 물음 3) 전환사채

#### (1) 자본요소(전환권대가)

**1단계 — 부채요소 PV (시장이자율 10%)**
- 만기 (원금 + 상환할증금) = 1,100,000, 표시이자 50,000
- PV = 1,100,000 × 0.7513 + 50,000 × 2.4868 = 826,430 + 124,340 = **950,770**

**2단계 — 자본요소**
- 1,000,000 − 950,770 = **49,230**

#### 정답
**전환권대가 = 49,230원**

#### (2) 20×2.1.1 50% 전환 시 20×2년 NI 영향

전환은 자본거래(부채요소 + 전환권대가 → 자본금 + 주식발행초과금)이므로 **그 자체는 NI에 영향 없음**. NI 영향은 **잔여 50% 부채요소의 이자비용**뿐.

**1단계 — 20×1년말 부채요소 BV**
- 950,770 × 1.10 − 50,000 = 1,045,847 − 50,000 = **995,847**

**2단계 — 20×2.1.1 잔여 50% (전환분 이자비용 없음)**
- 잔여 = 995,847 × 0.5 = **497,924**

**3단계 — 20×2년 이자비용**
- 497,924 × 10% = **49,792**

#### 정답
**20×2년 NI 영향 = (−)49,792원**

#### (3) 20×3.1.1 잔여 50% 재매입 시 20×3년 NI 영향

K-IFRS 제32호 AG33–AG35: 재매입대가를 **재매입일 현행이자율(12%)** 로 부채요소 PV를 산정 → 부채요소·자본요소로 배분. 거래원가는 같은 비율로 배분. 부채요소 손익은 PL, 자본요소는 자본거래.

**1단계 — 20×3.1.1 잔여 50% 부채요소 BV**
- 497,924 × 1.10 − 25,000 = 547,716 − 25,000 = **522,716**

**2단계 — 재매입 시 부채요소 PV (12%)**
- (550,000 + 25,000) × 0.8929 = 575,000 × 0.8929 = **513,418**
- 자본요소 배분액 = 520,000 − 513,418 = 6,582

**3단계 — 거래원가 10,000 비례 배분**
- 부채요소 거래원가 = 10,000 × 513,418/520,000 = **9,873**
- 자본요소 거래원가 = 127

**4단계 — 부채요소 상환손익 (PL)**
- 522,716 − 513,418 − 9,873 = **−575**

#### 정답
**20×3년 NI 영향 = (−)575원**

## [문제 2] 유형자산 교환·재평가, 법인세, 연결 (30점)

### 물음 1) 영업용 차량 교환

#### (1) (주)세무의 손상차손과 환입

상업적 실질 있고 **받은 자산의 공정가치가 더 명백** → 취득원가 = 받은 자산 FV = **220,000**.

**1단계 — 매년 감가상각비**
- (220,000 − 20,000) / 5 = **40,000/년**

**2단계 — 20×2년말 손상차손**
- 20×2년말 감가 후 BV = 220,000 − 40,000 × 2 = 140,000
- 회수가능액 110,000 → 손상차손 = **30,000** ①

**3단계 — 20×3년말 손상차손환입**
- 20×3년 감가 = (110,000 − 20,000) / 3 = 30,000
- 20×3년말 감가 후 BV = 80,000
- 환입 한도(손상 미발생 시 BV) = 220,000 − 40,000 × 3 = 100,000
- 환입 = min(95,000, 100,000) − 80,000 = **15,000** ②

#### 정답
**① 손상차손 30,000원, ② 손상차손환입 15,000원**

#### (2) (주)대한의 재평가모형 적용 영향

(주)대한 입장: 자기차량 BV = 200,000, 받은 차량 FV(더 명백) = 240,000, 현금 20,000 지급. **취득원가 = 240,000**, 잔존 4년·정액·잔존가 0, 연수합계법(4+3+2+1=10).

**1단계 — 20×1년**
- 감가비 = 240,000 × 4/10 = 96,000
- 감가 후 BV = 144,000, 20×1년말 FV = 160,000
- 재평가잉여금(OCI) = **+16,000** ①

**2단계 — 20×2년**
- 잔여 3년, 연수합계 3+2+1=6 → 감가비 = 160,000 × 3/6 = 80,000
- 감가 후 BV = 80,000, 20×2년말 FV = 50,000 → 재평가손실 30,000
- 16,000은 OCI(재평가잉여금) 차감, 14,000은 PL 재평가손실
- 20×2년 NI 영향 = −80,000(감가비) − 14,000(재평가손실) = **(−)94,000** ②

#### 정답
**① 20×1년 OCI 영향 +16,000원, ② 20×2년 NI 영향 (−)94,000원**

### 물음 2) 이연법인세

#### (1) 20×1년말 DTA / DTL

차감할(가산할) 일시적 차이를 **소멸시점 적용세율** 로 곱한다. 세율: 20×1·20×2년 20%, 20×3년 25%, 20×4년 이후 30%.

| 항목 | 차이 | 소멸시점 | 세율 | 이연법인세 |
|------|------|----------|------|------------|
| 재고자산평가손실 | +20,000 | 20×2 | 20% | DTA 4,000 |
| 제품보증충당부채 | +15,000 | 20×2/×3/×4 각 5,000 | 20/25/30% | DTA 1,000+1,250+1,500 = 3,750 |
| 정기예금미수이자 | −20,000 | 20×2 | 20% | DTL 4,000 |
| 환급금이자 5,000 | 영구적(익금불산입) | — | — | — |
| 벌금 10,000 | 영구적(손금불산입) | — | — | — |

#### 정답
**① DTA = 7,750원, ② DTL = 4,000원**

#### (2) 20×2년 법인세비용·DTA·DTL 변동

**1단계 — 20×2년말 DTA**
- 보증충당부채 잔여 10,000: 5,000×25% + 5,000×30% = 2,750
- 감가상각비 한도초과 40,000(20×3∼20×6 각 10,000): 10,000×25% + 10,000×30%×3 = 11,500
- DTA = **14,250** (변동 +6,500)

**2단계 — 20×2년말 DTL**
- FVPL 평가이익 12,000(20×3 처분 예정): 12,000×25% = 3,000
- DTL = **3,000** (변동 −1,000)

**3단계 — 20×2년 과세소득 (회계 NI 700,000)**
- 전기 차이 소멸: 재고 −20,000, 보증 −5,000, 미수이자 +20,000
- 당기 신규: FVPL 평가이익 −12,000, 감가상각 한도초과 +40,000, 자기주식처분이익 +8,000(자본거래), 접대비 한도초과 +30,000
- 과세소득 = 700,000 − 20,000 − 5,000 + 20,000 − 12,000 + 40,000 + 8,000 + 30,000 = **761,000**

**4단계 — 당기법인세와 자본조정**
- 당기법인세 = 761,000 × 20% = 152,200
- 자기주식처분이익 관련 세효과(자본 직접 조정) = 8,000 × 20% = 1,600
- PL 당기법인세 = 152,200 − 1,600 = 150,600

**5단계 — PL 법인세비용**
- 150,600 − 6,500(DTA 증가) − 1,000(DTL 감소) = **143,100**

#### 정답
**① 법인세비용 143,100원**
**② 20×2년말 DTA 영향 = +6,500원 (잔액 14,250)**
**③ 20×2년말 DTL 영향 = (−)1,000원 (잔액 3,000)**

### 물음 3) 연결재무제표

취득일 (20×1.1.1):
- (주)대한 순자산 FV = 80,000 + 5,000(토지) + 15,000(건물) = 100,000
- NCI(FV 비례) = 100,000 × 20% = 20,000
- 영업권 = 100,000 − 80,000 = 20,000

연결조정 항목(매년):
- 토지 평가차액 5,000은 **20×1년 처분으로 전액 실현** → 20×1년 처분이익 5,000 차감
- 건물 추가 감가 = 15,000 / 5 = 3,000/년
- 상향거래 미실현이익(대한→세무, 매출이익 10,000): 20×1년 미판매 20% → 미실현 2,000(20×1) → 20×2년 실현 +2,000
- 하향거래 미실현이익(세무→대한, 매출이익 4,000): 20×1년 미판매 40% → 미실현 1,600(20×1) → 20×2년 실현 +1,600

#### (1) 20×1년

**1단계 — 대한 조정 후 NI**
- 20,000 − 5,000(토지) − 3,000(건물) − 2,000(상향) = 10,000

**2단계 — NCI 귀속 NI**
- 10,000 × 20% = **2,000** ①

**3단계 — 지배기업 귀속 NI**
- 세무 별도 NI 50,000 − 1,600(하향) + 10,000 × 80% = 50,000 − 1,600 + 8,000 = **56,400** ②

#### 정답
**① NCI 귀속 NI 2,000원, ② 지배기업 귀속 NI 56,400원**

#### (2) 20×2년

**1단계 — 대한 조정 후 NI**
- 30,000 − 3,000(건물) + 2,000(상향 실현) = 29,000

**2단계 — 세무 별도 조정**
- 60,000 − 4,000(배당수익 제거 5,000×80%) + 1,600(하향 실현) = 57,600

**3단계 — 지배기업 귀속 NI**
- 57,600 + 29,000 × 80% = 57,600 + 23,200 = **80,800** ①

**4단계 — 비지배지분 (잔액)**
- 20×1년말 NCI = 20,000 + 2,000 = 22,000
- 20×2년: NI 귀속 +29,000×20% = +5,800, 배당 −5,000×20% = −1,000
- 20×2년말 NCI = 22,000 + 5,800 − 1,000 = **26,800** ②

#### 정답
**① 지배기업 귀속 NI 80,800원, ② 비지배지분 26,800원**

## [문제 3] 결합원가 + 종합원가 + 전부·변동원가 (20점)

### 자료 정리
- 제1공정 착수 1,000단위 → 완성 850(A 150 + B 700) + 재공품 100(전환 50%) + 정상공손 25 + 비정상공손 25
- 재료원가 50,000(시점투입), 전환원가 66,500(고정)
- 검사: 종료시점(재공품은 미통과)
- 제2공정: B 700 → C 700, 재공품 0, 추가 재료 42,000, 추가 전환 56,000
- 판매가: A 320, C 300

### 물음 1) 제1공정 결합원가 배부

**1단계 — 완성품환산량**
- 재료: 850 + 100 + 50 = 1,000
- 전환: 850 + 50(재공품 100×0.5) + 50(공손 100%) = 950

**2단계 — 단위당 원가**
- 재료 = 50,000 / 1,000 = 50
- 전환 = 66,500 / 950 = 70 → 합계 120/단위

**3단계 — 정상공손 → 완성품 가산 (재공품은 검사 미통과)**
- 완성품 = 850 × 120 + 25 × 120 = 102,000 + 3,000 = **105,000**
- 비정상공손 = 25 × 120 = 3,000 (당기비용)

**4단계 — NRV법 결합원가 배분**
- A NRV = 150 × 320 = 48,000
- B NRV = 700 × 300 − (42,000 + 56,000) = 210,000 − 98,000 = 112,000
- 총 NRV = 160,000
- A 배분 = 105,000 × 48/160 = **31,500**
- B 배분 = 105,000 × 112/160 = **73,500**

#### 정답
**① 결합원가 105,000원, ② 제품A 31,500원, ③ 중간제품B 73,500원**

### 물음 2) 제2공정 완성품 원가

**전공정원가 73,500 + 재료 42,000 + 전환 56,000 = 171,500원**

### 물음 3) 전부원가 당기순이익

**1단계 — 매출**
- A: 150 × 320 = 48,000, C: 700 × 300 = 210,000 → 합계 258,000

**2단계 — 매출원가 (전량 판매)**
- A 31,500 + C 171,500 = 203,000

**3단계 — 비정상공손비 −3,000**

#### 정답
**당기순이익 = 258,000 − 203,000 − 3,000 = 52,000원**

### 물음 4) 변동원가계산

**1단계 — 결합 변동원가 (재료원가만, 전환원가는 고정)**
- 단위당 변동결합원가 = 50,000 / 1,000 = 50
- 완성품 변동결합원가 = 850 × 50 + 25 × 50(정상공손) = 43,750
- 비정상공손 변동분 = 25 × 50 = **1,250**

**2단계 — NRV법 배분 (NRV는 실제 자료 기준)**
- A 배분 = 43,750 × 48/160 = 13,125
- B 배분 = 43,750 × 112/160 = 30,625

**3단계 — 제품별 변동매출원가**
- A = 13,125, C = 30,625 + 42,000(2공정 변동재료) = 72,625
- 합계 = **85,750**

**4단계 — 당기순이익**
- 매출 258,000 − 변동매출원가 85,750 = 공헌이익 172,250
- 고정원가(전환원가) = 66,500 + 56,000 = 122,500
- 비정상공손(변동) = 1,250
- 당기순이익 = 172,250 − 122,500 − 1,250 = **48,500**

#### 정답
**① 매출원가 85,750원, ② 비정상공손원가 1,250원, ③ 당기순이익 48,500원**

### 물음 5) 차이 분석

전부원가 NI(52,000) − 변동원가 NI(48,500) = **3,500원** 차이.

**원인**: 제1공정 기말재공품 100단위(전환 완성도 50% → 환산량 50)에 포함된 **고정전환원가 50 × 70 = 3,500원**이 전부원가계산에서는 자산(재고)으로 이연되지만, 변동원가계산에서는 당기 비용으로 처리되기 때문이다. 즉, 기말재고에 포함된 고정제조간접원가만큼 전부원가 NI가 더 크다.

### 물음 3) 생산방식 의사결정

| 방식 | 불황(40%) | 호황(60%) | 기대이익 |
|------|-----------|-----------|----------|
| 자동화 | 65,000 | 160,000 | 122,000 |
| 반자동 | 90,000 | 100,000 | 96,000 |
| 수작업 | 75,000 | 80,000 | 78,000 |

#### (1) 제외 가능 방식

**수작업 방식**은 불황(75 < 90)·호황(80 < 100) 모두에서 **반자동 방식에 절대 열위(dominated)**. 어떤 정보가 와도 선택될 수 없으므로 의사결정 대상에서 제외 가능.

#### (2) 완전정보의 기대가치

**1단계 — 완전정보 하 기대이익 (각 상태에서 최선 선택)**
- 불황 → 반자동 90,000, 호황 → 자동화 160,000
- 0.4 × 90,000 + 0.6 × 160,000 = 36,000 + 96,000 = **132,000**

**2단계 — 정보 없을 때 최적 = 자동화 122,000**

#### 정답
**완전정보 기대가치 = 132,000 − 122,000 = 10,000원**

#### (3) 불완전정보

**1단계 — 사전·조건부확률**
- P(불황) = 0.4, P(호황) = 0.6
- P(R1|불황) = 0.8, P(R1|호황) = 0.2
- P(R2|불황) = 0.2, P(R2|호황) = 0.8
- P(R1) = 0.8 × 0.4 + 0.2 × 0.6 = 0.44, P(R2) = 0.56

**2단계 — R2 예측 시 사후확률**
- P(불황 | R2) = (0.2 × 0.4) / 0.56 = 0.08 / 0.56 = 1/7
- P(호황 | R2) = 0.48 / 0.56 = 6/7

**3단계 — R2 예측 시 각 방식 기대이익**
- 자동화 = (1/7) × 65,000 + (6/7) × 160,000 = (65,000 + 960,000)/7 = 1,025,000/7 ≈ **146,429**
- 반자동 = (1/7) × 90,000 + (6/7) × 100,000 = 690,000/7 ≈ 98,571

→ **R2 시 최적은 자동화, 기대이익 146,429원** ①

**4단계 — 불완전정보 하 기대이익**
- P(R1) × E[반자동|R1] + P(R2) × E[자동화|R2]
- = 0.44 × 92,727 + 0.56 × 146,429
- 정확 계산:
  - 0.44 × 92,727 = 90,000 × 0.32 + 100,000 × 0.12 = 28,800 + 12,000 = **40,800**
  - 0.56 × 146,429 = 0.08 × 65,000 + 0.48 × 160,000 = 5,200 + 76,800 = **82,000**
- 합계 = **122,800**

**5단계 — 불완전정보 기대가치**
- 122,800 − 122,000 = **800**

#### 정답
**① R2 예측 시 최적 = 자동화, 기대이익 146,429원**
**② 불완전정보 기대가치 = 800원** (컨설팅사에 지불할 수 있는 최대 금액)
