본 문제는 4개 독립적 물음(30점)으로 구성된 종합문제이다. 물음 1)은 현금흐름표(직접법·간접법) 작성, 물음 2)는 K-IFRS 제1008호상 회계정책 변경 허용사유, 물음 3)은 재평가모형 최초 적용(정책변경—전진법 예외)과 감가상각방법 변경(추정변경—전진법), 물음 4)는 자본화 차입원가·재고자산·선급보험료 오류수정 효과를 묻는다. 회계학 1부 전형적 종합문제로, 각 물음에서 K-IFRS 처리원칙을 정확히 이해하고 기계적으로 계산을 수행할 수 있는지를 평가한다.

## [문제 2] 현금흐름표·회계정책 변경·회계추정 변경·오류수정 종합 (30점)

> **[문제]**
> 물음 1)~물음 4)는 각각 독립적 상황이다. (주)세무는 유통업을 영위하며 20×2년 재무상태표·포괄손익계산서가 제시된다. 이자·배당금 수취는 영업활동, 이자·배당금 지급은 재무활동으로 분류한다. 20×2년 중 장부금액 ₩100,000인 건물 처분(처분이익 ₩18,000), 20×2년 초 액면 ₩500,000 사채를 ₩455,000에 할인발행, 자본잉여금 ₩60,000 자본금 전입, 자기주식 ₩39,000에 취득, 20×1년 말 단기차입금·단기대여금은 20×2년 중 모두 상환·회수.

### 물음 1) 현금흐름표 (14점)

#### (1) 직접법 — 영업활동·투자활동·재무활동 현금흐름

**① 고객으로부터 유입된 현금**

매출채권(순액) 분석:

$$\text{기초 40,000} + \text{매출 950,000} - \text{손상차손 8,000} - \text{회수액} = \text{기말 31,000}$$

- 회수액 = 40,000 + 950,000 − 8,000 − 31,000 = **₩951,000**

> **① = 951,000**

**② 공급자에 대한 현금유출**

- 매입액 = 매출원가 510,000 + 재고자산 증가 (118,000−70,000) = 558,000
- 매입채무 증가 = 60,000 − 32,000 = 28,000
- 공급자 지급 = 558,000 − 28,000 = **₩530,000**

> **② = (530,000)**

**③ 종업원 및 판매관리활동 현금유출**

- 손익계산서상 급여 105,000 + 기타판관비 85,000 = 190,000
- 미지급판관비 감소 = 8,000 − 4,000 = 4,000 (현금유출 가산)
- (감가상각비·매출채권손상차손은 비현금항목이므로 제외)
- 현금유출 = 190,000 + 4,000 = **₩194,000**

> **③ = (194,000)**

**영업에서 창출된 현금** = 951,000 − 530,000 − 194,000 = **₩227,000**

**④ 이자수취**

- 이자수익 5,000 − 미수이자 증가 (3,000−2,000) = **₩4,000**

> **④ = 4,000**

**⑤ 법인세납부**

- 법인세비용 42,000 + 미지급법인세 감소 (4,000−2,000) = **₩44,000**

> **⑤ = (44,000)**

**영업활동 순현금흐름** = 227,000 + 4,000 − 44,000 = **₩187,000**

---

**⑥ 토지의 취득**

- 토지 증가 = 420,000 − 300,000 = 120,000
- 이 중 재평가차익 15,000은 비현금
- 현금취득 = 120,000 − 15,000 = **₩105,000**

> **⑥ = (105,000)**

**⑦ 건물의 취득**

건물(순액) 증감 분석:

$$\text{기초 250,000} - \text{감가상각비 48,000} - \text{처분 100,000} + \text{취득} = \text{기말 580,000}$$

- 취득 = 580,000 − 250,000 + 48,000 + 100,000 = **₩478,000**

> **⑦ = (478,000)**

**⑧ 건물의 처분**

- 처분대가 = 장부금액 100,000 + 처분이익 18,000 = **₩118,000**

> **⑧ = 118,000**

**단기대여금**: 기초 10,000 전액 회수 + 기말 30,000 신규대여
- 회수 ₩10,000 / 대여 ₩(30,000)

**투자활동 순현금흐름** = −105,000 − 478,000 + 10,000 + 118,000 − 30,000 = **₩(485,000)**

---

**⑨ 이자지급**

- 사채할인발행차금 상각 = 45,000 − 30,000 = 15,000 (비현금)
- 현금이자 = 이자비용 50,000 − 사채할인발행차금 상각 15,000 − 미지급이자 증가 (8,000−6,000)
- 이자지급 = 50,000 − 15,000 − 2,000 = **₩33,000**

> **⑨ = (33,000)**

**⑩ 배당금지급**

이익잉여금 분석:

$$\text{기초 50,000} + \text{당기순이익 125,000} - \text{배당금} = \text{기말 150,000}$$

- 배당금 = 50,000 + 125,000 − 150,000 = **₩25,000**

> **⑩ = (25,000)**

**기타 재무활동**:
- 단기차입금 상환 ₩(150,000) / 차입 ₩140,000
- 사채발행 ₩455,000
- 자기주식취득 ₩(39,000)
- (자본잉여금 60,000 자본금 전입은 현금흐름 없음)

**재무활동 순현금흐름** = −150,000 − 33,000 − 25,000 + 455,000 + 140,000 − 39,000 = **₩348,000**

**검증**: 187,000 + (−485,000) + 348,000 = ₩50,000 (현금증가액 일치) ✓

#### (2) 간접법 — 영업활동 관련 자산·부채 변동액(순액)

이자수취·이자지급·법인세납부가 모두 별도 표시되므로, **미수이자·미지급이자·미지급법인세 변동은 영업활동 자산·부채 변동에서 제외**한다.

| 항목 | 변동 | 가감 |
|---|---:|---:|
| 매출채권 감소 (40,000→31,000) | 9,000 | +9,000 |
| 재고자산 증가 (70,000→118,000) | 48,000 | −48,000 |
| 매입채무 증가 (32,000→60,000) | 28,000 | +28,000 |
| 미지급판매비와관리비 감소 (8,000→4,000) | 4,000 | −4,000 |
| **순액** | | **−15,000** |

> **영업활동 관련 자산·부채 변동액(순액) = (−15,000)**

**검증**: 법인세차감전순이익 167,000 + 감가상각비 48,000 − 유형자산처분이익 18,000 − 이자수익 5,000 + 이자비용 50,000 + 자산·부채 변동 (−15,000) = ₩227,000 (영업에서 창출된 현금과 일치) ✓

### 물음 2) 회계정책 변경 허용 사유 (2점)

K-IFRS 제1008호 문단 14에 따라 회계정책의 변경은 다음 두 경우에 한하여 허용한다.

1. **한국채택국제회계기준에서 회계정책의 변경을 요구하는 경우**
2. **회계정책의 변경을 반영한 재무제표가 거래, 기타 사건 또는 상황이 기업의 재무상태, 재무성과 또는 현금흐름에 미치는 영향에 대하여 신뢰성 있고 더 목적적합한 정보를 제공하는 경우**

### 물음 3) 원가모형→재평가모형 적용과 감가상각방법 변경 (8점)

#### 상황 (1) — 원가모형에서 재평가모형으로 변경

K-IFRS 제1008호 문단 17에 따라, **원가모형에서 재평가모형으로의 최초 적용은 회계정책 변경이지만 제1008호의 소급법 규정을 적용하지 않고 제1016호의 재평가모형 규정에 따라 전진적으로 적용**한다. 따라서 비교표시되는 20×1년분은 원가모형 그대로 유지한다.

**20×1년 비교 표시 (원가모형 그대로)**
- 취득원가 = 500,000
- 감가상각누계액 = 500,000 ÷ 10 = 50,000
- 장부금액 = 450,000

> **① 20×1년 유형자산(총장부금액) = 500,000**

**20×2년 (재평가모형 최초 적용)**

먼저 20×2년 감가상각:
- 감가상각비 = 500,000 ÷ 10 = 50,000
- 누적 감가상각누계액 = 100,000
- 장부금액 = 400,000

공정가치 480,000으로 재평가 → 변동비율 = 480,000 / 400,000 = 1.2 (총장부금액·감가상각누계액을 비례수정)

- 총장부금액 = 500,000 × 1.2 = **600,000**
- 감가상각누계액 = 100,000 × 1.2 = **120,000**
- 순장부금액 = 480,000 ✓

> **② 20×2년 감가상각누계액 = 120,000**

#### 상황 (2) — 감가상각방법·잔존내용연수 변경 (회계추정 변경, 전진법)

K-IFRS 제1008호 문단 36에 따라 회계추정의 변경은 **전진적으로** 적용한다.

**20×1년 (정액법, 변경 전)**
- 감가상각비 = 500,000 ÷ 10 = **50,000**
- 20×1년 말 장부금액(순액) = 450,000

> **② 20×1년 감가상각비 = 50,000**

**20×2년 (연수합계법, 잔존내용연수 8년)**
- 연수합계 = 8 × (8+1) ÷ 2 = 36
- 20×2년 감가상각비 = 450,000 × (8/36) = 100,000
- 20×2년 말 장부금액(순액) = 450,000 − 100,000 = **350,000**

> **① 20×2년 유형자산(순액) = 350,000**

### 물음 4) 오류수정 — 20×3년 기초이익잉여금·당기순이익 변동 (6점)

#### 오류 1 — 차입원가 자본화 누락 + 취득세·등록세 비용처리

자본화 차입원가 120,000(20×1년 80,000 + 20×2년 40,000)과 취득시점 취득·등록세 50,000은 건물 원가에 포함되어야 한다. 건물은 20×3년 초 완성 → 20×3년부터 정액법 감가상각(20년, 잔존가치 0).

**연도별 손익 영향(올바른 처리−잘못된 처리)**

| 연도 | 잘못된 처리 | 올바른 처리 | 손익 영향 |
|---|---|---|---:|
| 20×1년 | 이자비용 80,000 | 자본화 0 | +80,000 |
| 20×2년 | 이자비용 40,000 | 자본화 0 | +40,000 |
| 20×3년 | 일반관리비 50,000 + 감가상각비 0 | 자본화 + 감가상각비 (170,000÷20=8,500) | +50,000 − 8,500 = +41,500 |

- **① 20×3년 기초이익잉여금 변동 = 80,000 + 40,000 = +120,000**
- **② 20×3년 당기순이익 변동 = +41,500**

#### 오류 2 — 재고자산 오류 (자기수정오류)

기말재고가 과소계상되면 매출원가가 과대 → 순이익 과소.

| 연도 | 기초재고 오류 | 기말재고 오류 | 매출원가 오류 | 순이익 오류 |
|---|---|---|---|---:|
| 20×1년 | — | 4,000 과소 | 4,000 과대 | 4,000 과소 |
| 20×2년 | 4,000 과소 | 5,000 과대 | (4,000+5,000)=9,000 과소 | 9,000 과대 |
| 20×3년 | 5,000 과대 | 6,000 과소 | (5,000+6,000)=11,000 과대 | 11,000 과소 |

오류 수정 시 손익 변동(올바른 값−보고된 값):
- 20×1년 순이익: +4,000
- 20×2년 순이익: −9,000
- 20×3년 순이익: +11,000

- **③ 20×3년 기초이익잉여금 변동 = 4,000 + (−9,000) = −5,000**
- **④ 20×3년 당기순이익 변동 = +11,000**

#### 오류 3 — 선급보험료 오류

**(가) 20×2.7.1 가입 보험료 36,000 (월 3,000)** — 전액 비용처리
- 올바른 비용: 20×2년 18,000(7~12월), 20×3년 18,000(1~6월)
- 보고된 비용: 20×2년 36,000, 20×3년 0
- 손익 영향: 20×2년 +18,000, 20×3년 −18,000

**(나) 20×3.7.1 갱신 보험료 48,000 (월 4,000)** — 전액 비용처리
- 올바른 비용: 20×3년 24,000(7~12월), 20×4년 24,000
- 보고된 비용: 20×3년 48,000
- 손익 영향: 20×3년 +24,000

종합:
- 20×2년 순이익 변동: +18,000
- 20×3년 순이익 변동: −18,000 + 24,000 = +6,000

- **⑤ 20×3년 기초이익잉여금 변동 = +18,000**
- **⑥ 20×3년 당기순이익 변동 = +6,000**
