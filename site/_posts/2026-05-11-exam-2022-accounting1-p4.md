## [물음 1] 매출조업도차이 · 변동예산차이 (4점)

> **[문제]**
> 20×1년 변동원가계산 실제공헌이익 손익계산서를 기준으로 ① 매출조업도차이와 ② 변동예산차이는 각각 얼마인가? (유리/불리 표시)

### 풀이

**1단계 — 차이분석 프레임 설정**

고정예산차이는 (실제 ↔ 변동예산 ↔ 고정예산) 두 단계로 분해된다.

- 매출조업도차이 = 변동예산 영업이익 − 고정예산 영업이익
- 변동예산차이 = 실제 영업이익 − 변동예산 영업이익

**2단계 — 매출조업도차이**

수량(조업도)만 변하고 단위당 공헌이익·고정원가는 예산 그대로이므로:

$$\text{매출조업도차이} = (\text{실제판매량} - \text{예산판매량}) \times \text{예산 단위당 공헌이익}$$

- 대입: $(4{,}200 - 4{,}500) \times \text{￦}70 = -300 \times 70 = -\text{￦}21{,}000$
- **매출조업도차이 = ￦21,000 (불리)**

**3단계 — 변동예산 영업이익 산정**

변동예산 = 실제판매량(4,200단위)에 예산 단위당 공헌이익·예산 고정원가를 적용한 값.

- 변동예산 공헌이익: $4{,}200 \times 70 = \text{￦}294{,}000$
- 변동예산 고정원가: $135{,}000 + 78{,}000 = \text{￦}213{,}000$
- 변동예산 영업이익: $294{,}000 - 213{,}000 = \text{￦}81{,}000$

**4단계 — 변동예산차이**

$$\text{변동예산차이} = \text{실제 영업이익} - \text{변동예산 영업이익} = 158{,}000 - 81{,}000 = \text{￦}77{,}000$$

- **변동예산차이 = ￦77,000 (유리)**

**검산** — 고정예산차이 = 실제(158,000) − 고정예산(4,500×70 − 213,000 = 102,000) = ￦56,000(유리). 이는 매출조업도차이(△21,000) + 변동예산차이(+77,000) = ￦56,000과 일치. ✓

### 정답
- ① 매출조업도차이 = **￦21,000 (불리)**
- ② 변동예산차이 = **￦77,000 (유리)**

## [물음 2] 변동원가계산 vs 전부원가계산 영업이익 차이 (4점)

> **[문제]**
> ① 20×1년 변동원가계산과 전부원가계산 실제 영업이익의 차이금액과 ② 그 이유는? (재공품 없음)

### 풀이

**1단계 — 차이공식 확인**

두 방법의 영업이익 차이는 기말재고에 포함된 고정제조간접원가 − 기초재고에 포함된 고정제조간접원가, 즉 **재고에 흡수된 고정OH의 변동분**에서 발생한다.

$$\text{전부원가 영업이익} - \text{변동원가 영업이익} = \text{기말재고 고정OH} - \text{기초재고 고정OH}$$

**2단계 — 재고 변동 확인**

〈기본자료〉의 "매연도에 실제 생산된 제품 A는 각 연도에 모두 판매된다" → 매년 생산량 = 판매량. 따라서:

- 기초제품재고 = 0, 기말제품재고 = 0
- 재공품 없음(문제 단서)
- 즉 재고에 흡수된 고정OH = 0 (양쪽 시점 모두)

**3단계 — 차이금액 산정**

$$\text{차이금액} = 0 - 0 = \text{￦}0$$

### 정답
- ① 영업이익 차이금액 = **￦0**
- ② 이유: 재공품이 없고 생산량(4,200단위) = 판매량(4,200단위)이어서 기초·기말 제품재고가 모두 0이므로, 당기에 발생한 **고정제조간접원가 ￦140,000이 두 방법 모두 전액 당기비용으로 인식**된다. 즉 재고에 이연되는 고정OH가 없어 두 원가계산 방식의 영업이익이 동일해진다.

## [물음 3] 제조간접원가 능률차이·소비차이를 이용한 역산 (4점)

> **[문제]**
> 단위당 표준직접노무시간 1시간, 제조간접원가는 직접노무시간 기준 배부. 능률차이 ￦1,500(불리), 소비차이 ￦3,500(불리). ① 실제 직접노무시간, ② 변동제조간접원가 실제발생액?

### 풀이

**1단계 — 표준배부율 산정**

- 변동OH 표준배부율: 단위당 변동OH ￦15 ÷ 단위당 표준노무시간 1시간 = **￦15/시간**
- 고정OH 표준배부율: ￦135,000 ÷ (4,500단위 × 1시간) = **￦30/시간**
- 표준허용시간(SQ): 실제생산 4,200단위 × 1시간 = **4,200시간**

**2단계 — 능률차이로 실제노무시간(AQ) 역산**

3분법에서 제조간접원가의 능률차이는 변동OH에서만 발생한다(고정OH는 시간 변화에 영향받지 않음).

$$\text{능률차이} = (AQ - SQ) \times \text{변동OH 표준배부율}$$
$$1{,}500 = (AQ - 4{,}200) \times 15 \;\;\Rightarrow\;\; AQ - 4{,}200 = 100$$

- **① 실제 직접노무시간 AQ = 4,300시간**

**3단계 — 소비차이로 변동OH 실제발생액 역산**

3분법 소비차이(예산차이)는 변동OH 소비차이 + 고정OH 예산차이의 합산이다.

$$\text{소비차이} = \big[\text{실제 변동OH} - (AQ \times \text{변동OH 표준배부율})\big] + \big[\text{실제 고정OH} - \text{예산 고정OH}\big]$$

- 고정OH 예산차이 = 실제 ￦140,000 − 예산 ￦135,000 = ￦5,000 (불리)
- 따라서 변동OH 소비차이 = 3,500 − 5,000 = **△￦1,500 (유리)**
- 변동OH 소비차이 = 실제 변동OH − (4,300시간 × ￦15) = 실제 변동OH − ￦64,500 = △1,500
- 실제 변동OH = 64,500 − 1,500 = **￦63,000**

**검산** — 능률차이(불리) 1,500 + 변동OH 소비차이(유리) △1,500 = 변동OH 총차이 0. 그리고 고정OH 예산차이(불리) 5,000을 더하면 합산 소비차이 ￦3,500(불리)와 일치. ✓

### 정답
- ① 실제 직접노무시간 = **4,300시간**
- ② 변동제조간접원가 실제발생액 = **￦63,000**

## [물음 4] 매출배합하 손익분기점 — 추가 고정원가 (4점)

> **[문제]**
> 제품 B 추가. 단위당 예산공헌이익 ￦80, A:B = 7:3, 추가 후 A의 BEP = 4,067단위. 추가 후 고정원가 증가액?

### 풀이

**1단계 — 가중평균 단위당 공헌이익**

- 제품 A 단위당 공헌이익 = 200 − 130 = **￦70**
- 제품 B 단위당 공헌이익 = **￦80**
- 배합비 7:3 적용:

$$\bar{cm} = \frac{70 \times 7 + 80 \times 3}{10} = \frac{490 + 240}{10} = \text{￦}73$$

**2단계 — 총 BEP 산정**

A가 전체의 7/10이고 A의 BEP가 4,067단위이므로:

$$\text{총 BEP} = \frac{4{,}067}{0.7} = 5{,}810 \text{단위}$$

(검산: 5,810 × 7/10 = 4,067 ✓)

**3단계 — 추가 후 총 고정원가 산정**

$$\text{총 고정원가} = \text{총 BEP} \times \bar{cm} = 5{,}810 \times 73 = \text{￦}424{,}130$$

**4단계 — 고정원가 증가액**

- 기존 고정원가: 135,000 + 78,000 = ￦213,000
- 증가액: 424,130 − 213,000 = **￦211,130**

### 정답
**고정원가 증가액 = ￦211,130**

## [물음 5] 직접재료 구입예산(금액) (4점)

> **[문제]**
> 직접재료 수량표준 2kg/단위, 기초재고 700kg, 기말재고는 차기 예산판매량의 10% 생산분. 기초재공품 150단위(완성도 30%), 기말재공품 100단위(완성도 20%). 직접재료는 공정초 전량 투입. 20×1년 직접재료 구입예산(금액)?

### 풀이

**1단계 — 직접재료 단가**

단위당 직접재료원가 ￦40 ÷ 수량표준 2kg = **￦20/kg**

**2단계 — 완성품 생산량 (예산판매량 = 예산생산량)**

〈기본자료〉 안정적 시장환경 → 매년 4,500단위 생산·판매 → 차기연도 예산판매량도 **4,500단위**로 본다. 20×1년 완성품 = 4,500단위.

**3단계 — 당기 착수량 (직접재료 투입량 산정 기준)**

직접재료가 공정초에 모두 투입되므로, 직접재료가 투입되는 단위 = 당기 착수량.

$$\text{당기 착수량} = \text{당기 완성품} + \text{기말재공품} - \text{기초재공품}$$
$$= 4{,}500 + 100 - 150 = 4{,}450 \text{단위}$$

(기초재공품 150단위는 전기에 직접재료가 이미 투입되었으므로 당기 투입에서 제외)

**4단계 — 직접재료 사용량(kg)**

$$\text{사용량} = 4{,}450 \text{단위} \times 2\text{kg} = 8{,}900\text{kg}$$

**5단계 — 직접재료 기말재고**

차기 예산판매량 4,500단위 × 10% = 450단위 생산분 → 450 × 2kg = **900kg**

**6단계 — 직접재료 구입량(kg)**

재고흐름식: 기초 + 구입 = 사용 + 기말

$$\text{구입량} = \text{사용} + \text{기말} - \text{기초} = 8{,}900 + 900 - 700 = 9{,}100\text{kg}$$

**7단계 — 직접재료 구입예산(금액)**

$$9{,}100\text{kg} \times \text{￦}20/\text{kg} = \text{￦}182{,}000$$

### 정답
**직접재료 구입예산 = ￦182,000**

## 종합 답안 요약

| 물음 | 정답 |
|------|------|
| 1) 매출조업도차이 | **￦21,000 (불리)** |
| 1) 변동예산차이 | **￦77,000 (유리)** |
| 2) 영업이익 차이 | **￦0** (생산=판매, 재공품 無 → 재고흡수 고정OH 변동 없음) |
| 3) 실제 직접노무시간 | **4,300시간** |
| 3) 변동OH 실제발생액 | **￦63,000** |
| 4) 고정원가 증가액 | **￦211,130** |
| 5) 직접재료 구입예산 | **￦182,000** |

### 채점 포인트
- **물음 1**: 변동예산은 실제판매량 × 예산 단위당 공헌이익 − 예산 고정원가. 매출조업도차이는 수량차이 × 예산 단위당 공헌이익만으로 떨어져야 함 (가격·원가차이는 변동예산차이 쪽).
- **물음 2**: "차이가 0인 이유"를 단순히 "생산=판매"로만 쓰면 부족. **재공품도 없으므로 어느 시점에도 재고에 고정OH가 흡수되지 않는다**는 점을 명시.
- **물음 3**: 능률차이는 변동OH만, 소비차이는 변동OH 소비차이 + 고정OH 예산차이의 합산이라는 3분법 구조를 정확히 적용. 고정OH 예산차이(￦5,000 불리)를 분리해야 변동OH 실제값이 나옴.
- **물음 4**: 매출배합하 BEP는 가중평균 공헌이익 사용. A의 BEP에서 총 BEP 역산 → 총 고정원가 → 증가액 순서.
- **물음 5**: 재공품을 고려할 때 **직접재료가 공정초 전량 투입**이므로 사용량 기준은 "당기 착수량"이지 완성품 환산량이 아님. 차기 예산판매량은 안정적 환경 단서로 4,500단위로 추정.
