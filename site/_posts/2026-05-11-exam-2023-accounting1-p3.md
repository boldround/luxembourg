본 문제는 결합원가계산을 종합원가계산·공손회계·NRV 배부·전부원가/변동원가 비교까지 묶어 묻는 종합형이다. 제1공정에서 종합원가계산으로 결합원가 총액을 산정하고(공손 처리 포함), 이를 NRV법으로 결합제품 A·B에 배부한 뒤, 제2공정 추가가공을 거쳐 손익을 계산한다. 마지막에 전부원가계산과 변동원가계산의 NI 차이를 기말재공품에 포함된 고정전환원가로 설명하는 것이 핵심이다. 단위당 재료원가 ₩50, 전환원가 ₩70(=66,500/950)로 깔끔히 떨어지므로 계산 자체는 평이하나, 정상공손원가 가산 대상(완성품만, 기말재공품은 검사 미통과)을 잘못 잡으면 모든 후속 계산이 어긋나는 문제이다.

## [문제 3] 결합원가계산 — 종합원가·NRV배부·전부/변동원가 NI 비교 (20점)

> **[자료 요약]**
> - 제1공정: 착수 1,000단위 → 완성 850단위(제품A 150 + 중간제품B 700), 기말재공품 100단위(전환원가 완성도 50%), 정상공손 25단위, 비정상공손 25단위. 검사시점=공정 종료시점. 공손품 처분가치 ₩0.
> - 제1공정 투입: 재료원가 ₩50,000(변동), 전환원가 ₩66,500(고정). 재료는 공정 시작시점 전량 투입.
> - 제2공정: 중간제품B 전량을 제품C로 가공. 완성 700단위, 기말재공품 없음, 공손·감손 없음. 추가 재료원가 ₩42,000(변동), 전환원가 ₩56,000(고정).
> - 판매: 제품A @₩320, 제품C @₩300. 당기 전량 판매. 판매관리비 없음.
> - 결합원가는 NRV법으로 배부(실제판매가치·실제원가 사용).

### 풀이

#### 사전 계산 — 제1공정 종합원가계산

**물량흐름 검증**
- 1,000(착수) = 850(완성) + 100(기말재공품) + 25(정상공손) + 25(비정상공손) ✓

**완성품환산량(FIFO/평균법 차이 없음 — 기초재공품 없음, 설립 1차연도)**

| 구분 | 재료원가 | 전환원가 |
|---|---:|---:|
| 완성품 | 850 | 850 |
| 정상공손(완성도 100%, 검사=종료시점) | 25 | 25 |
| 비정상공손(완성도 100%) | 25 | 25 |
| 기말재공품(재료 100%, 전환 50%) | 100 | 50 |
| **합계** | **1,000** | **950** |

**단위당 원가**
- 재료원가: 50,000 ÷ 1,000 = **₩50/단위**
- 전환원가: 66,500 ÷ 950 = **₩70/단위**
- 합계 단위당 원가(완성도 100% 기준): ₩120

**원가 1차 배분 (정상공손 가산 전)**

| 구분 | 재료 | 전환 | 합계 |
|---|---:|---:|---:|
| 완성품(850) | 42,500 | 59,500 | 102,000 |
| 정상공손(25) | 1,250 | 1,750 | 3,000 |
| 비정상공손(25) | 1,250 | 1,750 | 3,000 |
| 기말재공품 | 5,000 | 3,500 | 8,500 |
| **합계** | **50,000** | **66,500** | **116,500** ✓ |

**정상공손원가 배부**
- 검사시점이 공정 종료시점이므로 검사를 통과한 물량은 **완성품 850단위뿐**(기말재공품은 완성도 50%로 검사 미통과).
- 따라서 정상공손원가 ₩3,000 전액을 완성품에 가산 → **완성품 결합원가 = 102,000 + 3,000 = ₩105,000**.

#### 물음 1) 제1공정 결합원가 배부

**결합원가 총액 = ₩105,000** (= 완성품원가 102,000 + 정상공손원가 3,000)

**NRV 산정**

| 결합제품 | 최종판매가치 | 추가가공원가 | NRV | 구성비 |
|---|---:|---:|---:|---:|
| 제품A(150단위) | 150 × 320 = 48,000 | 0 | **48,000** | 30% |
| 중간제품B → 제품C(700단위) | 700 × 300 = 210,000 | 42,000 + 56,000 = 98,000 | **112,000** | 70% |
| **합계** | | | **160,000** | 100% |

**결합원가 배부**
- ① 제품A: 105,000 × (48,000/160,000) = 105,000 × 0.3 = **₩31,500**
- ② 중간제품B: 105,000 × (112,000/160,000) = 105,000 × 0.7 = **₩73,500**

| 항목 | 금액 |
|---|---:|
| 결합원가 총액 | **₩105,000** |
| ① 제품A에 배부된 결합원가 | **₩31,500** |
| ② 중간제품B에 배부된 결합원가 | **₩73,500** |

#### 물음 2) 제2공정 완성품원가 (3점)

제2공정은 공손·감손·기말재공품이 없고 700단위 전량 완성.

- 전공정원가(B에 배부된 결합원가): 73,500
- 추가 재료원가: 42,000
- 추가 전환원가: 56,000

**완성품원가 = 73,500 + 42,000 + 56,000 = ₩171,500**

#### 물음 3) 전부원가계산 당기순이익 (3점)

| 항목 | 금액 |
|---|---:|
| 매출액 (제품A: 150×320 + 제품C: 700×300) | 258,000 |
| (-) 매출원가 (A: 31,500 + C: 171,500) | (203,000) |
| 매출총이익 | 55,000 |
| (-) 비정상공손원가 (25 × 120) | (3,000) |
| **당기순이익** | **₩52,000** |

> 공손품 처분가치가 ₩0이고 판매관리비가 없으며 당기 전량 판매되어 기말제품재고는 없다. 비정상공손 25단위는 정상공손과 동일하게 완성도 100%(검사=종료시점)이므로 단위당 ₩120이 적용된다.

#### 물음 4) 변동원가계산 (4점)

변동원가계산에서는 **전환원가(고정원가)는 전액 기간비용**으로 처리한다. 결합원가 산정 시 변동제조원가(재료원가)만 결합원가로 본다.

**제1공정 결합 변동원가 산정**

| 구분 | 변동원가(재료) |
|---|---:|
| 완성품(850) | 42,500 |
| 정상공손(25) | 1,250 |
| 비정상공손(25) | 1,250 |
| 기말재공품(100) | 5,000 |
| 합계 | 50,000 |

- 정상공손 변동원가 1,250을 완성품에 가산 → **완성품 결합 변동원가 = 42,500 + 1,250 = ₩43,750**

**NRV 배부 비율**: 시장가치(실제판매가치) 기반의 NRV 비율은 회계방식과 무관하게 동일하게 0.3 : 0.7 적용.
- 제품A: 43,750 × 0.3 = 13,125
- 중간제품B: 43,750 × 0.7 = 30,625

**제품별 변동제조원가**
- 제품A(추가가공 없음): **13,125**
- 제품C(B 결합변동원가 + 제2공정 변동재료): 30,625 + 42,000 = **72,625**

**① 매출원가(변동매출원가)**
- 당기 전량 판매: 13,125 + 72,625 = **₩85,750**

**② 비정상공손원가(변동만)**
- 25단위 × 변동단위원가 ₩50 = **₩1,250**

**③ 당기순이익**

| 항목 | 금액 |
|---|---:|
| 매출액 | 258,000 |
| (-) 변동매출원가 | (85,750) |
| 공헌이익 | 172,250 |
| (-) 고정원가 (제1공정 66,500 + 제2공정 56,000) | (122,500) |
| (-) 비정상공손원가(변동) | (1,250) |
| **당기순이익** | **₩48,500** |

| 항목 | 금액 |
|---|---:|
| ① 매출원가 | **₩85,750** |
| ② 비정상공손원가 | **₩1,250** |
| ③ 당기순이익 | **₩48,500** |

#### 물음 5) NI 차이 원인 (2점)

**차이금액**: 전부원가계산 NI 52,000 - 변동원가계산 NI 48,500 = **₩3,500**

**차이 원인**:

전부원가계산에서는 고정전환원가가 제품(재공품) 원가에 포함되어 자산으로 이연되지만, 변동원가계산에서는 당기에 발생한 고정전환원가 전액(₩122,500)이 발생기간의 기간비용으로 처리된다. 본 문제에서 제품 기말재고는 없으나 **제1공정 기말재공품 100단위(전환원가 완성도 50%)**가 존재하므로, 여기에 포함된 고정전환원가만큼 두 방법의 NI가 차이 난다.

$$\text{기말재공품 포함 고정전환원가} = 100\text{단위} \times 50\% \times \text{₩}70 = \text{₩}3,500$$

이 ₩3,500은 전부원가계산에서는 자산(재공품)으로 차기 이연되어 당기비용에서 제외되지만, 변동원가계산에서는 당기에 모두 비용처리되므로 **전부원가 NI가 변동원가 NI보다 ₩3,500 큰 결과**가 된다.

### 정답 요약

| 물음 | 항목 | 금액 |
|---|---|---:|
| 1 | 결합원가 총액 | ₩105,000 |
| 1-① | 제품A에 배부된 결합원가 | ₩31,500 |
| 1-② | 중간제품B에 배부된 결합원가 | ₩73,500 |
| 2 | 제2공정 완성품원가 | ₩171,500 |
| 3 | 전부원가계산 당기순이익 | ₩52,000 |
| 4-① | 변동원가계산 매출원가 | ₩85,750 |
| 4-② | 변동원가계산 비정상공손원가 | ₩1,250 |
| 4-③ | 변동원가계산 당기순이익 | ₩48,500 |
| 5 | NI 차이 = 기말재공품(100단위×50%×@70) 고정전환원가 | ₩3,500 |

### 채점 포인트

- **검사시점 처리**: 검사가 공정 종료시점이므로 정상공손원가는 완성품에만 가산(기말재공품은 미배부). 이 부분을 잘못 잡으면 결합원가 총액이 달라져 모든 후속 계산이 틀린다.
- **완성품환산량 분리**: 재료(시작시점 100% 투입)와 전환원가(완성도 비례) 환산량이 다름. 공손은 검사시점 기준 완성도 100%.
- **NRV법**: 추가가공원가(₩98,000)를 차감한 NRV(48,000 : 112,000 = 3 : 7) 비율로 배부. 깔끔히 0.3 : 0.7로 떨어짐.
- **변동원가계산 결합원가**: 결합 자체에 포함되는 원가만 변동원가(재료)로 한정. NRV 비율(시장가치 기반)은 회계방식 불문 동일.
- **NI 차이의 원천**: 본 문제처럼 기말제품재고가 없는 경우에도 **재공품에 포함된 고정전환원가**가 차이의 원천이 된다는 점을 명시.
- **빈출 함정**:
  - 정상공손원가를 기말재공품에도 안분(검사시점 통과 여부 미확인)
  - 비정상공손에 변동원가계산 시 고정원가 포함
  - 변동원가계산 NRV 산정에서 추가가공원가에 고정전환원가까지 차감(시험에서는 NRV 비율을 회계방식과 무관하게 동일하게 보는 풀이가 표준)
