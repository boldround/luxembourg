본 문제는 단일 사업부(부품사업부)의 예산자료를 기본으로 하여 **CVP(현금분기점·안전한계율·영업레버리지도)**, **특별주문 의사결정**, **사업부 간 최소대체가격**, **학습곡선과 외부구매 의사결정**까지 원가관리회계의 의사결정 영역을 종합적으로 묻는 전형적 종합문제이다. 핵심은 (i) 직접노무시간 제약 하 매출배합 유지, (ii) 법인세 효과(환급 가능)와 감가상각비를 반영한 현금분기점 공식, (iii) 누적평균시간 학습곡선의 정확한 적용이다.

## [문제 4] 부품사업부 예산·CVP·대체가격 종합 (20점)

> **[문제]**
> (주)세무 부품사업부(이익중심점)는 부품 A·B·C를 생산·판매한다. 연간 가용 직접노무시간 1,800시간, 법인세율 20%(단일세율). 매출 및 원가자료, 고정제조간접원가 ₩84,600(감가상각비 ₩28,200 포함), 직접노무임률 ₩35/시간, 변동제조간접원가는 직접노무시간에 비례. 다음 각 물음(상호독립)에 답하시오.

### 풀이 — 기본 단위당 자료 정리

| 구분 | 부품 A | 부품 B | 부품 C |
| --- | ---: | ---: | ---: |
| 단위당 판매가격 | 400 | 800 | 400 |
| 단위당 직접재료원가 | 160 | 380 | 196 |
| 단위당 직접노무원가 | 70 | 98 | 42 |
| 단위당 변동제조간접원가 | 70 | 98 | 42 |
| **단위당 변동원가 합계** | **300** | **576** | **280** |
| **단위당 공헌이익** | **100** | **224** | **120** |
| 단위당 직접노무시간 | 2.0h | 2.8h | 1.2h |
| 시간당 공헌이익 | 50 | 80 | 100 |

- 매출배합비율(매출액 기준): A:B:C = 100,000 : 200,000 : 200,000 = **20% : 40% : 40%**
- 가중평균 공헌이익률: $0.2 \times 25\% + 0.4 \times 28\% + 0.4 \times 30\% = \mathbf{28.2\%}$
- 1,000단위(=1,800시간) 기준 총공헌이익: $250 \times 100 + 250 \times 224 + 500 \times 120 = \mathbf{141{,}000}$
- 영업이익(세전) = 141,000 − 84,600 = **₩56,400**

---

### 물음 1) 세후목표영업이익 ₩51,888 (직접노무시간 최대 2,000h, 매출배합 동일)

#### (1) 현금흐름분기점 매출액

세후 영업현금흐름(OCF) = 세후순이익 + 감가상각비. 법인세 환급 가능하므로 손실 시 (음의)법인세도 그대로 반영.

$$\text{OCF} = (S - V - F)(1-t) + D = 0$$

$$\Rightarrow CM = F - \frac{D}{1-t} = 84{,}600 - \frac{28{,}200}{0.8} = 84{,}600 - 35{,}250 = 49{,}350$$

매출배합 유지 시 가중평균 공헌이익률 28.2% 적용:

$$S^* = \frac{49{,}350}{0.282} = \mathbf{175{,}000\text{원}}$$

**검증**: 매출 175,000 → CM 49,350 → 세전OI −35,250 → 환급 7,050 → 세후NI −28,200 → OCF = −28,200 + 28,200 = 0 ✓

> **현금흐름분기점 매출액 = ₩175,000**

#### (2) 세후목표영업이익 ₩51,888 달성을 위한 매출액 증가분

세전 목표영업이익 = $51{,}888 / 0.8 = 64{,}860$
필요 공헌이익 = $64{,}860 + 84{,}600 = 149{,}460$
필요 매출액 = $149{,}460 / 0.282 = \mathbf{530{,}000}$

**노무시간 검증**: 매출 530,000일 때 단위수
A 265단위, B 265단위, C 530단위 → 시간 $265 \times 2 + 265 \times 2.8 + 530 \times 1.2 = 530 + 742 + 636 = 1{,}908$h ≤ 2,000h ✓

> **매출액 증가분 = 530,000 − 500,000 = ₩30,000**

---

### 물음 2) 안전한계율·영업레버리지도, 매출 10% 증가 시 세후현금흐름

원래 매출 ₩500,000 기준:

- 손익분기점 매출 = $84{,}600 / 0.282 = 300{,}000$
- 안전한계 = $500{,}000 - 300{,}000 = 200{,}000$
- **안전한계율(MoS ratio) = 200,000 / 500,000 = 40%**
- **영업레버리지도(DOL) = CM / OI = 141,000 / 56,400 = 2.5**

매출 10% 증가 시 영업이익 변동률 = $\text{DOL} \times 10\% = 25\%$
새 세전OI = $56{,}400 \times 1.25 = 70{,}500$
세후NI = $70{,}500 \times 0.8 = 56{,}400$
세후 현금흐름(OCF) = 세후NI + 감가상각비 = $56{,}400 + 28{,}200 = \mathbf{84{,}600}$

**노무시간 검증**: 매출 550,000 → A 275, B 275, C 550단위 → $275 \times 2 + 275 \times 2.8 + 550 \times 1.2 = 1{,}980$h ≤ 2,000h ✓

> **안전한계율 40%, 영업레버리지도 2.5, 세후현금흐름 ₩84,600**

### 물음 3) (주)국세 특별주문 — 부품 D 수락 시 세후영업이익 변동

부품 D 자료: 가격 ₩800, DM ₩450, 단위당 노무시간 2h
- DL: $2 \times 35 = 70$
- VOH: $2 \times 35 = 70$
- 단위당 변동원가 = $450 + 70 + 70 = 590$
- 단위당 공헌이익 = $800 - 590 = 210$

전환 노무시간 = 부품A 500h + 부품B 70h = **570시간**
부품 D 생산량 = $570 / 2 = 285$단위 → 추가 CM = $285 \times 210 = 59{,}850$

희생되는 기존 부품 CM:
- 부품 A 전량 250단위: $250 \times 100 = 25{,}000$
- 부품 B $70 / 2.8 = 25$단위: $25 \times 224 = 5{,}600$
- 합계 희생 CM = $30{,}600$

세전 증분이익 = $59{,}850 - 30{,}600 = 29{,}250$
세후 증분이익 = $29{,}250 \times 0.8 = \mathbf{23{,}400}$ 증가

> **세후영업이익 변동 = + ₩23,400 (증가)**

### 물음 4) 부품 H 50단위 내부대체 — 단위당 최소대체가격

부품 H 자료: 부품 B와 동일하나 DM만 변경(+₩20/단위), 따라서 단위당 노무시간 2.8h 동일.
- 단위당 변동원가 = $(380 + 20) + 98 + 98 = 596$

총 소요 노무시간 = $50 \times 2.8 = 140$시간
기본자료의 가용시간은 1,800h(완전가동 상태)이므로 H 생산을 위해서는 **기존 생산을 140h만큼 희생**해야 함.

기존 부품의 시간당 공헌이익: A=50, B=80, C=100 → **부품 A부터 감축**(가장 낮음)
- 감축 부품 A 단위 = $140 / 2 = 70$단위 (≤ 250단위 ✓)
- 희생 CM = $70 \times 100 = 7{,}000$

기회원가 단위당 = $7{,}000 / 50 = 140$
(또는 H 1단위당 2.8h 사용 → A 1.4단위 희생 → $1.4 \times 100 = 140$)

최소대체가격(자기 사업부 이익 불감소 조건):

$$\text{TP}_{\min} = \text{단위당 변동원가} + \text{단위당 기회원가} = 596 + 140 = \mathbf{736}$$

> **단위당 최소대체가격 = ₩736**

### 물음 5) 학습곡선 적용 묶음생산 vs 외부구매

부품 C를 125단위/묶음으로 생산, 80% 누적평균시간 학습곡선.

**1묶음(125단위) 직접노무시간**: $5{,}250 / 35 = 150$시간

| 묶음 누적수(X) | 누적평균시간/묶음 | 누적총시간 |
| ---: | ---: | ---: |
| 1 | 150 | 150 |
| 2 | $150 \times 0.8 = 120$ | 240 |
| 4 | $120 \times 0.8 = 96$ | **384** |

500단위(=4묶음) 변동제조원가:
- DM: $500 \times 196 = 98{,}000$
- DL: $384 \times 35 = 13{,}440$
- VOH: $384 \times 35 = 13{,}440$
- **합계 = ₩124,880 → 단위당 변동제조원가 = $124{,}880 / 500 = \mathbf{249.76}$**

내부 대체가격 = $249.76 + 120 = \mathbf{369.76}$/단위
외부공급 가격 = $\mathbf{380}$/단위

완성사업부가 외부에서 500단위 전량 구매 시:
- 외부구매원가 = $500 \times 380 = 190{,}000$
- 내부대체원가 = $500 \times 369.76 = 184{,}880$
- 원가 증가 = $190{,}000 - 184{,}880 = 5{,}120$

(완성사업부 입장에서 매출은 변하지 않고 부품 매입원가만 증가)

> **완성사업부 세전영업이익 변동 = (−) ₩5,120 (감소)**
