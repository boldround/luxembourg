본 문제는 30점 배점의 두 물음으로 구성된 종합문제다. **물음 1)** 은 K-IFRS 1033(주당이익)에서 ① 가중평균유통보통주식수 산정(유상증자·무상증자 소급, 자기주식 취득·소각), ② 잠재적 보통주(옵션·전환우선주·전환사채) 3종의 희석성 검토와 순차적 가산법을 종합적으로 묻는 단골 유형이다. **물음 2)** 는 K-IFRS 1019(종업원급여)에서 자산인식상한(asset ceiling)이 발생하는 경우의 OCI 처리, 자산천장효과의 이자처리, 재측정요소 분리 산정을 다루는 고난도 응용이다. 두 물음 모두 단순 공식 암기보다 흐름표(roll-forward) 작성 능력이 결정적이다.

## [문제 1] 주당이익과 확정급여제도 (30점)

> **[문제]**
> 각 물음은 상호 독립적이다.
> - **물음 1)** ㈜세무의 20×1년도 자본·잠재적 보통주 변동 자료가 주어졌다. 가중평균유통보통주식수, 기본·희석 주당계속영업이익 및 주당이익을 계산하시오.
> - **물음 2)** 20×1년 말 확정급여제도를 도입한 ㈜세무의 두 회계연도 자료가 주어졌다. 자산인식상한을 고려한 OCI 영향, 재무상태표 표시액, 당기순이익 영향을 계산하시오.

---

### 물음 1) 주당이익 (15점)

#### (1) 기본주당계속영업이익·기본주당이익

**1단계 — 가중평균유통보통주식수 산정**

무상증자(7/1, 10%)는 K-IFRS 1033 문단26에 따라 **기초 및 그 이전 발행 주식 모두에 소급 적용**한다. 4/1 유상증자분에도 7/1 시점 보유자에게 무상으로 부여되므로 마찬가지로 소급한다.

| 일자 | 거래 | 변동주식수 | 무상증자 소급 (×1.1) | 누적 유통주식수 |
|------|------|------------|---------------------|----------------|
| 1/1 | 기초 | 150,000 | 165,000 | 165,000 |
| 4/1 | 유상증자(공정가) | +45,000 | +49,500 | 214,500 |
| 7/1 | 무상증자 10% | +19,500 | (소급반영됨) | 214,500 |
| 9/1 | 자기주식 취득 | −6,375 | −6,375 | 208,125 |
| 12/1 | 자기주식 소각 | (자기주식 내 처리) | 0 | 208,125 |

> 자기주식 소각은 이미 보유한 자기주식의 회계상 제거이므로 **유통보통주식수에는 영향이 없다**.

가중평균유통보통주식수:

$$
165{,}000 \times \tfrac{12}{12} + 49{,}500 \times \tfrac{9}{12} - 6{,}375 \times \tfrac{4}{12}
= 165{,}000 + 37{,}125 - 2{,}125 = \mathbf{200{,}000\text{주}}
$$

**2단계 — 우선주 배당금 차감**

전환우선주 배당금 = 80,000주 × ₩1,000 × 8% = **₩6,400,000** (당기 지급 결의·비누적적이므로 결의분 차감)

**3단계 — 기본 EPS 산정**

| 구분 | 분자 | 분모 | 기본 EPS |
|------|------|------|----------|
| 계속영업이익 | 16,400,000 − 6,400,000 = **10,000,000** | 200,000 | **₩50** |
| 당기순이익 | 15,200,000 − 6,400,000 = **8,800,000** | 200,000 | **₩44** |

##### 정답
- **① 기본주당계속영업이익 = ₩50**
- **② 기본주당이익 = ₩44**

---

#### (2) 희석주당계속영업이익·희석주당이익

**1단계 — 잠재적 보통주별 EPS 효과(individual effect) 계산**

| 잠재적 보통주 | 분자 환원(세후) | 분모 증가 | 개별 EPS 효과 |
|--------------|----------------|----------|---------------|
| 옵션 100,000개 (행사가 ₩600, 평균시장 ₩1,200) | ₩0 | 100,000 − (100,000×600/1,200) = **50,000주** | ₩0 |
| 전환사채 ₩10,000,000 (이자율 6.25%) | 10,000,000 × 6.25% × (1−0.2) = **₩500,000** | 10,000,000 ÷ 400 × 2 = **50,000주** | ₩10 |
| 전환우선주 80,000주 (배당률 8%) | 우선주배당 환원 = **₩6,400,000** | 80,000 × 2 = **160,000주** | ₩40 |

> 옵션은 자기주식법(K-IFRS 1033 문단45-47)을 적용한다. 행사가 ₩600 < 평균시장가 ₩1,200이므로 희석가능성이 있다.

**2단계 — 희석성 검정 (계속영업이익 기준, 작은 효과부터 순차 가산)**

K-IFRS 1033 문단44: 희석성은 **계속영업이익에 따른 보통주 EPS**를 기준으로 판정한다.

| 단계 | 누적 분자 | 누적 분모 | EPS | 판정 |
|------|----------|----------|-----|------|
| 기본 | 10,000,000 | 200,000 | 50.00 | (기준) |
| + 옵션 | 10,000,000 | 250,000 | 40.00 | 50→40 **희석** ✓ |
| + 전환사채 | 10,500,000 | 300,000 | 35.00 | 40→35 **희석** ✓ |
| + 전환우선주 | 16,900,000 | 460,000 | ≈36.74 | 35→36.74 **반희석** ✗ |

> 전환우선주는 **반희석효과**를 가지므로 희석 EPS 계산에서 **제외**한다 (K-IFRS 1033 문단43).

**3단계 — 희석 EPS 산정**

희석주당계속영업이익:

$$
\frac{10{,}000{,}000 + 500{,}000}{200{,}000 + 50{,}000 + 50{,}000} = \frac{10{,}500{,}000}{300{,}000} = \mathbf{₩35}
$$

희석주당이익(당기순이익 기준, 동일한 희석성 잠재적 보통주만 가산):

$$
\frac{8{,}800{,}000 + 500{,}000}{300{,}000} = \frac{9{,}300{,}000}{300{,}000} = \mathbf{₩31}
$$

##### 정답
- **① 희석주당계속영업이익 = ₩35**
- **② 희석주당이익 = ₩31**

### 물음 2) 확정급여제도 (15점)

#### (1) 20×1년 OCI 영향 및 순확정급여부채(자산)

**1단계 — 20×1년 말 도입 시점 회계처리**

20×1년 말 처음 제도를 도입했으므로 당기 중 근무원가·이자원가는 발생하지 않고, **도입 시점의 DBO 인식·사외적립자산 출연만** 발생한다.

| 항목 | 금액 |
|------|------|
| 확정급여채무(DBO) | ₩500,000 |
| 사외적립자산(FVPA) | ₩600,000 |
| 차액(잠재적 순확정급여자산) | ₩100,000 |
| 자산인식상한 | ₩60,000 |
| **자산천장효과 (초과액)** | **₩40,000** |

**2단계 — 자산인식상한 적용**

K-IFRS 1019 문단64: 순확정급여자산은 **자산인식상한을 한도로** 인식하며, 한도 초과액은 **재측정요소(OCI)** 로 처리한다.

- 재무상태표상 인식액 = min(100,000, 60,000) = **₩60,000**
- 자산천장효과 ₩40,000 → **OCI 손실** (기타포괄이익 감소)

##### 정답
- **① 20×1년 기타포괄이익에 미치는 영향 = ₩40,000 감소**
- **② 20×1년 말 순확정급여자산 = ₩60,000 (자산)**

---

#### (2) 20×2년 말 OCI 누계액 및 당기순이익 영향

**1단계 — 20×2년 DBO Roll-forward**

| 항목 | 금액 | 비고 |
|------|------|------|
| 기초 DBO | 500,000 | |
| 이자원가 | +20,000 | 500,000 × 4% (PL) |
| 당기근무원가 | +800,000 | (PL) |
| 퇴직급여 지급 | −200,000 | |
| 소계 | 1,120,000 | |
| **보험수리적손실 (역산)** | **+80,000** | (OCI 손실) |
| **기말 DBO** | **1,200,000** | |

**2단계 — 20×2년 사외적립자산 Roll-forward**

| 항목 | 금액 | 비고 |
|------|------|------|
| 기초 FVPA | 600,000 | |
| 이자수익 | +24,000 | 600,000 × 4% (PL) |
| 퇴직급여 지급 | −200,000 | |
| 사용자 출연 | +900,000 | |
| 소계 | 1,324,000 | |
| **재측정이익 (역산)** | **+76,000** | (OCI 이익) |
| **기말 FVPA** | **1,400,000** | |

**3단계 — 자산인식상한(자산천장) Roll-forward**

| 항목 | 금액 | 비고 |
|------|------|------|
| 기초 자산천장효과 누적 | 40,000 | |
| 자산천장 이자 | +1,600 | 40,000 × 4% (PL, 순이자수익 차감) |
| 소계 | 41,600 | |
| **자산천장 재측정 (역산)** | **+58,400** | (OCI 손실) |
| **기말 자산천장효과** | **100,000** | (1,400,000 − 1,200,000) − 100,000 |

> K-IFRS 1019 문단123A·124: 자산인식상한 효과의 변동 중 **할인율을 적용한 이자 부분은 PL(순이자)** 로, **나머지는 OCI(재측정)** 로 분리한다.

**4단계 — 20×2년 OCI 영향**

| OCI 항목 | 금액 |
|----------|------|
| DBO 보험수리적손실 | −80,000 |
| FVPA 재측정이익 | +76,000 |
| 자산천장 재측정 | −58,400 |
| **20×2년 OCI 변동(합계)** | **−62,400** |

20×2년 말 기타포괄손익누계액:

$$
\underbrace{-40{,}000}_{20\times1\text{년 말 누계}} + \underbrace{(-62{,}400)}_{20\times2\text{년 변동}} = \mathbf{-₩102{,}400}
$$

**5단계 — 20×2년 당기순이익 영향**

당기손익에 반영되는 항목만 집계한다.

| PL 항목 | 금액 |
|---------|------|
| 당기근무원가 | −800,000 |
| DBO 이자원가 | −20,000 |
| FVPA 이자수익 | +24,000 |
| 자산천장 이자 (비용) | −1,600 |
| **당기순이익 영향** | **−797,600** |

> 검산(순이자 단순법): 기초 순확정급여자산(자산천장 적용 후) ₩60,000 × 4% = ₩2,400 순이자수익. 근무원가 ₩800,000과 합산 시 −800,000 + 2,400 = **−₩797,600** 일치.

##### 정답
- **① 20×2년 말 기타포괄손익누계액 = ₩102,400 손실**
- **② 20×2년 당기순이익에 미치는 영향 = ₩797,600 감소**

### 빈출 함정 정리
- 자기주식 **취득**은 가중평균에서 차감하지만, 자기주식 **소각**은 이미 보유한 자기주식 내부 처리이므로 유통주식수에 영향이 없다.
- 무상증자 비율은 **기초·기중 발행분 모두에 소급**한다 (공정가치 유상증자 포함).
- 희석성 검정은 반드시 **계속영업이익 기준 EPS**로 하며, 개별 EPS 효과가 작은 잠재적 보통주부터 순차 가산하다 EPS가 다시 상승(반희석)하는 시점부터는 제외한다.
- 자산인식상한이 적용되는 경우, 자산천장효과의 변동 중 **할인율 부분은 PL**로, **나머지는 OCI**로 분리한다 — 전부 OCI로 처리하지 않도록 주의.
