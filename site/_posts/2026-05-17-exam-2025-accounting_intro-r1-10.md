2025년 회계학개론 1~10번은 K-IFRS 자산·부채 인식과 측정의 핵심 주제를 고르게 출제했다. 특히 **유형자산 교환(상대방 공정가치 명백)**, **복구충당부채 + 연수합계법**, **투자부동산→유형자산 대체(공정가치모형 ↔ 재평가모형)**, **무형자산 손상차손환입 한도**가 계산형으로 출제되어 단계 누락 시 오답 유도가 강했다. 말문제(매각예정·생물자산·주식기준보상·구조조정)는 K-IFRS 1105·1041·1102·1037호 단서·예외 조항을 정확히 기억해야 풀리는 정공법 문제였다.

## [문제 1] 유형자산 교환 — 상대방 공정가치가 더 명백할 때

**정답 ②** — (주)세무 처분이익 ₩200,000 / (주)한국 처분손익 ₩0

(주)세무의 건물 공정가치(3,800,000)가 더 명백하므로 **양사 모두 (주)세무 건물의 공정가치를 기준으로 측정**한다. (주)세무는 제공자산(건물)의 공정가치로 측정하므로 처분이익 = 3,800,000 − (5,100,000 − 1,500,000) = **200,000**. (주)한국은 취득자산(건물)의 공정가치 3,800,000을 기준으로 역산하여 제공한 기계장치의 공정가치 = 3,800,000 − 400,000(지급한 현금) = 3,400,000으로 인식, 장부금액 3,400,000과 동일하므로 처분손익 **0**.

- **함정**: 각자 자기가 제공한 자산의 공정가치를 쓰면 (주)한국에서 100,000 이익이 잡혀 ③⑤로 빠짐. "더 명백한" 측정치를 **양사가 공통으로 사용**해야 한다는 K-IFRS 1016호 문단 24~26이 핵심.

## [문제 2] 재고자산 보고금액

**정답 ⑤** — ₩156,000

각 항목의 소유권 귀속을 따져 (주)세무 재고에 합산한다.

| 구분 | 금액 | 포함 여부 |
|---|---:|---|
| 창고 재고 | 50,000 | ○ |
| A → FOB 선적지 매입 운송중 | 40,000 | ○ (이미 소유권 이전) |
| B에 FOB 도착지 판매 운송중 | 20,000 | ○ (도착 전 미이전) |
| 적송품 미판매분 (20,000 × 60%) | 12,000 | ○ |
| 시송품 매입 의사 미통보 (30,000 × 80%) | 24,000 | ○ |
| D 재구매약정 (실질 차입거래) | 10,000 | ○ |
| **합계** | **156,000** | |

- **함정**: D와의 재구매약정을 정상 판매로 보고 제외하면 146,000이 됨. **재구매가격(13,000) > 판매가격(12,000)** 인 약정은 K-IFRS 1115호 B66 적용 차입거래로 보아 재고 보유로 처리한다.

## [문제 3] 재고자산회전율

**정답 ①** — 5회

신용매출 = 기말매출채권(2,000) + 회수액(33,000) − 기초매출채권(1,000) = **34,000**
총매출 = 신용 34,000 + 현금 11,000 = **45,000**
매출원가 = 45,000 × (1 − 0.3) = **31,500**
기말재고 = 7,050 + 30,000 − 31,500 = **5,550**
평균재고 = (7,050 + 5,550) ÷ 2 = **6,300**

재고자산회전율 = 31,500 ÷ 6,300 = **5회**

- **함정**: 신용매출 계산에서 "회수 = 신용매출"로 착각하면 안 됨. **회수 + 기말 − 기초 = 신용매출** 관계를 매출채권 T계정으로 풀어야 한다.

## [문제 4] 매각예정비유동자산 — 옳지 않은 것

**정답 ④**

매각예정 비유동자산은 "공정가치에서 처분부대원가를 뺀 금액(NRV)과 장부금액 중 **작은 금액**"으로 측정한다(K-IFRS 1105호 문단 15). 보기 ④는 "큰 금액"이라 명백한 오류.

- **함정**: ③의 "1년 이후 매각 예상 시 처분부대원가를 현재가치로 측정"은 K-IFRS 1105호 문단 17에 명시된 옳은 표현이다.

## [문제 5] 복구충당부채 + 연수합계법 (월할)

**정답 ②** — ₩1,185,840

복구충당부채 = 400,000 × 0.7350 = **294,000**
설비 취득원가 = 3,900,000 + 294,000 = **4,194,000**
감가상각대상액 = 4,194,000 − 300,000(잔존가치) = **3,894,000**

연수합계법 (내용연수 4년, 합계 10) — 20×1년(4.1.~12.31., 9개월):
감가상각비 = 3,894,000 × 4/10 × 9/12 = **1,168,200**

복구충당부채 이자비용 = 294,000 × 8% × 9/12 = **17,640**

총 당기비용 = 1,168,200 + 17,640 = **1,185,840**

- **함정**: 잔존가치 300,000을 빼지 않고 4,194,000 전체에 4/10을 곱하면 ③의 1,275,840 근처로 유인. 연수합계법은 **잔존가치를 차감한 후** 분수를 곱한다.

## [문제 6] 투자부동산(공정가치모형) → 유형자산(재평가모형) 대체

**정답 ⑤** — ₩10,000 증가

20×2.5.1. 대체 시점 처리:
- 직전 장부금액(20×1.12.31. 공정가치) 980,000 → 대체일 공정가치 1,050,000
- 평가이익 70,000을 **당기손익**으로 인식하고 1,050,000으로 유형자산 대체

20×2.5.1.~12.31.(8개월) 감가상각비 = 1,050,000 ÷ 20년 × 8/12 = **35,000**

20×2.12.31. 재평가:
- 상각 후 장부금액 = 1,050,000 − 35,000 = 1,015,000
- 공정가치 990,000 → 재평가손실 25,000 (재평가잉여금 없으므로 **당기손익**)

20×2년 당기순이익 영향 = +70,000 − 35,000 − 25,000 = **+10,000 (증가)**

- **함정**: 공정가치모형 투자부동산에서 유형자산으로 대체 시 평가차액은 **기타포괄손익이 아닌 당기손익**이라는 점(K-IFRS 1040호 문단 60)을 놓치면 ②④로 빠짐.

## [문제 7] 생물자산 — 옳지 않은 것

**정답 ③**

K-IFRS 1041호 문단 22는 공정가치 측정 시 **자금조달, 수확 후 생물자산의 복구 관련 현금흐름은 포함하지 않는다**고 규정한다. ③은 "원가에 포함된다"고 잘못 서술. 생물자산은 최초인식 시점에 공정가치 − 처분부대원가로 측정하며, 그 측정에 들어가지 않는 항목을 임의로 원가화할 수 없다.

- **함정**: ②의 "최초인식 시점에 손실 발생 가능"은 처분부대원가 차감 효과로 흔히 발생하는 사례로, 옳은 진술이다.

## [문제 8] 무형자산 손상차손 / 손상차손환입

**정답 ④** — (A) ₩1,800,000 / (B) ₩1,584,000

취득원가 = 4,500,000 + 7,500,000 = **12,000,000**, 사용 시작 20×2.5.1., 내용연수 10년(=120개월)

**20×2년 말** (8개월 상각): 상각비 = 12,000,000 × 8/120 = 800,000 → 장부금액 11,200,000. 회수가능액 11,500,000 ≥ 장부금액 → 손상 없음.

**20×3년 말** (12개월 상각): 상각비 1,200,000 → 장부금액 10,000,000. 회수가능액 8,200,000 → 손상차손 = 10,000,000 − 8,200,000 = **(A) 1,800,000**

**20×4년 말** (잔여 100개월 기준 상각): 상각비 = 8,200,000 × 12/100 = 984,000 → 장부금액 7,216,000.

손상되지 않았을 경우 가정 장부금액 = 12,000,000 × (1 − 32/120) = 12,000,000 − 3,200,000 = **8,800,000** (환입 한도)
회수가능액 8,900,000 > 8,800,000 → 환입 한도 적용

손상차손환입 = 8,800,000 − 7,216,000 = **(B) 1,584,000**

- **함정**: 환입 한도를 회수가능액 8,900,000으로 잡으면 1,684,000(⑤)으로 유인. K-IFRS 1036호 문단 117 — **손상 인식 전 가정 장부금액이 상한**이다.

## [문제 9] 주식기준보상 — 옳지 않은 것

**정답 ④**

K-IFRS 1102호 문단 B44A에 따르면, **가득기간 이후** 현금결제형이 주식결제형으로 변경되는 경우 그 지분상품은 **변경일(modification date)의 공정가치**로 측정하여 자본으로 처리한다. ④는 "가득기간 종료일을 기준으로" 측정한다고 했으나 옳지 않다 — 가득기간이 이미 끝났으므로 변경일이 기준일이 된다.

- **함정**: ①②③은 시장조건·비시장조건·비가득조건 처리(문단 21·21A)로 자주 출제되는 정확한 진술이다.

## [문제 10] 구조조정충당부채 — 옳은 것

**정답 ⑤**

K-IFRS 1037호 문단 80~83에 따른 정리:
- ① 새로운 제도·물류체계 구축 투자원가 → 미래 영업과 관련, **포함 X**
- ② 자산처분이익 → 구조조정충당부채 측정 시 **고려 X** (별도 처분 시점에 인식)
- ③ 계속적 활동 관련 지출 → **포함 X**
- ④ 간접비용 → **포함 X** (직접·필수적·계속활동과 무관한 지출만)
- ⑤ 구조조정 완료까지 영업손실은 충당부채로 인식하지 않지만, **손실부담계약 관련 영업손실은 충당부채로 인식** (문단 66~69) → 옳음

- **함정**: ②의 "자산처분이익 상계"는 K-IFRS가 명시적으로 금지하는 처리. 손실부담계약과 일반 영업손실을 구분해 ⑤를 정답으로 선별해야 한다.
