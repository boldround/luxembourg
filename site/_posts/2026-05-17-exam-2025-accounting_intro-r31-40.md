회계학개론 31-40번은 유형자산 교환(31) 외에는 모두 원가관리회계 영역으로, **CVP·의사결정·대체가격**에 집중되어 출제됐다. 35·36번은 확률·기대값 개념이 결합되어 단순 공식 암기로는 풀리지 않으며, 37번 보조부문 외주 의사결정과 38번 제약자원 하 특별주문은 절감·포기 공헌이익을 빠짐없이 식별하는 것이 관건이다. 39번 계단형 고정원가는 "최대이익이 더 높은 구간의 최대생산량"에서 나온다는 점에 주의해야 한다.

## [문제 31] 상업적 실질 있는 유형자산 교환 — 양사 처분손익

> **[문제]**
> (주)세무 건물(장부금액 3,600,000, 공정가치 3,800,000)과 (주)한국 기계장치(장부금액 3,400,000, 공정가치 3,500,000)를 교환하면서 (주)세무가 현금 400,000을 수취했다. 상업적 실질이 있고 (주)세무 건물의 공정가치가 더 명백할 때, 양사의 처분손익은?

### 풀이

**원칙** — 상업적 실질 있는 교환은 제공자산 공정가치로 측정하되, 취득자산 공정가치가 더 명백하면 그것을 사용한다.

**(주)세무 (건물 제공)** — 자기 건물 공정가치가 더 명백 → 자기 공정가치 사용
- 처분손익 = 3,800,000 − 3,600,000 = **200,000 이익**

**(주)한국 (기계장치 제공)** — 상대방 건물 공정가치가 더 명백 → 취득자산(건물) 공정가치 사용
- 받은 자산: 건물 3,800,000 − 지급 현금 400,000 = 순 취득가액 3,400,000
- 처분손익 = 3,400,000 − 3,400,000 = **0**

### 정답
**② (주)세무 처분이익 200,000 / (주)한국 처분손익 0**

**함정** — (주)한국 입장에서 자기 기계장치 공정가치 3,500,000을 그대로 쓰면 처분이익 100,000이 나오는 ③·⑤로 빠진다. 그러나 "상대방 자산의 공정가치가 더 명백"하다는 단서가 있으므로 그 값을 기준으로 역산해야 한다.

## [문제 32] 활동기준원가계산 — 고객별 판매관리비 배부

> **[문제]**
> 판매관리비 예산 500,000(급여 300,000, 기타 200,000)을 두 활동(고객주문처리·고객관계관리)에 배분(급여 60:40, 기타 70:30)한 뒤, 원가동인(주문횟수 80회, 고객수 30명)으로 배부한다. 12회 주문한 고객 A에게 배부될 판매관리비는?

### 풀이

**1단계 — 활동별 원가풀**
- 고객주문처리 = 300,000×60% + 200,000×70% = 180,000 + 140,000 = 320,000
- 고객관계관리 = 300,000×40% + 200,000×30% = 120,000 + 60,000 = 180,000

**2단계 — 활동별 배부율**
- 주문처리: 320,000 / 80회 = **4,000/회**
- 관계관리: 180,000 / 30명 = **6,000/명**

**3단계 — 고객 A 배부**
- 12회 × 4,000 + 1명 × 6,000 = 48,000 + 6,000 = **54,000**

### 정답
**⑤ 54,000**

**함정** — ④ 48,000은 주문처리 활동만 배부한 값으로 "고객 1명"의 관계관리 활동을 빠뜨린 오류이다.

## [문제 33] 다공정 손익분기점 (전공정 정상공손)

> **[문제]**
> A공정(고정원가 188,000, 단위당 변동원가 12, 종점에서 투입량의 10% 정상공손)을 거쳐 B공정(고정원가 160,000, 단위당 변동원가 20, 공손無)에서 완제품으로 가공·판매한다. 단위당 판매가 100일 때 B공정 완제품의 BEP 판매량은?

### 풀이

**1단계 — B공정 완제품 1단위당 A공정 투입소요량**
- A공정 양품률 90% → 완제품 1단위당 A공정 투입 1/0.9 단위 필요
- A공정 단위당 변동원가(완제품 기준) = 12 ÷ 0.9 = **40/3**

**2단계 — 완제품 단위당 변동원가**
- 40/3 + 20 = 100/3

**3단계 — 단위당 공헌이익**
- 100 − 100/3 = 200/3

**4단계 — BEP**
- 총 고정원가 = 188,000 + 160,000 = 348,000
- BEP = 348,000 ÷ (200/3) = **5,220 단위**

### 정답
**① 5,220 단위**

**함정** — 공손률을 무시하고 단위당 변동원가를 12+20=32로 두면 BEP=348,000/68 ≈ 5,118단위가 나와 보기에 없다. 정상공손원가를 양품(B공정 완제품)에 전부 흡수시키는 점이 핵심이다.

## [문제 34] 초변동원가계산 손익분기점

> **[문제]**
> 생산량 5,000단위, 단가 500. 단위당 직접재료 100, 직접노무 150, 변동제조간접 50, 변동판관 50. 총고정제조간접 300,000, 총고정판관 324,000. 초변동원가계산에 의한 BEP 판매량은?

### 풀이

초변동원가계산(super-variable costing)에서는 **직접재료원가만 제품원가**이고, 직접노무·변동제조간접원가·고정원가 전부 기간비용이다. 단, 직접노무·변동제조간접원가는 **생산량(5,000단위) 기준**으로 발생, 변동판관비는 **판매량(Q) 기준**으로 발생한다.

영업이익 = 0:

500Q − 100Q − 150×5,000 − 50×5,000 − 300,000 − 50Q − 324,000 = 0

350Q = 1,624,000

Q = **4,640 단위**

### 정답
**④ 4,640 단위**

**함정** — 직접노무·변동제조간접원가를 "변동원가"로 보고 단위당 차감하면 변동원가계산 BEP가 나와 ⑤ 등 다른 값이 나온다. 초변동원가계산에서는 두 원가가 생산량 기준 기간비용으로 이미 발생했다는 점에서 차이가 크다.

## [문제 35] 균등분포 하 두 확률의 합

> **[문제]**
> 단가 400, 단위당 변동원가 220, 고정원가 1,080,000. 매출액은 1,000,000~3,000,000의 균등분포. 3,000단위 이하 판매될 확률(a)과 손실이 발생하지 않을 확률(b)의 합은?

### 풀이

**1단계 — 손익분기점 매출액**
- 단위당 공헌이익 = 400 − 220 = 180
- BEP 수량 = 1,080,000 / 180 = 6,000단위 → BEP 매출액 = 2,400,000

**2단계 — 확률 (a): 3,000단위 이하 판매**
- 3,000단위 매출액 = 1,200,000
- a = (1,200,000 − 1,000,000) / (3,000,000 − 1,000,000) = 200,000/2,000,000 = **10%**

**3단계 — 확률 (b): 손실 미발생 = 매출액 ≥ BEP**
- b = (3,000,000 − 2,400,000) / 2,000,000 = 600,000/2,000,000 = **30%**

**합 = 10% + 30% = 40%**

### 정답
**① 40%**

**함정** — 균등분포가 수량이 아니라 **매출액**으로 주어져 있다는 점을 놓치면 확률을 잘못 계산한다. 3,000단위 → 매출액 1,200,000으로 환산해야 한다.

## [문제 36] 완전정보의 가치(EVPI)

> **[문제]**
> 공정조사비 10,000. 조사하지 않고 비정상이면 손실 70,000. 조사하는 경우 기대비용 19,000, 조사하지 않는 경우 기대비용 21,000. 완전정보의 대가로 지불할 수 있는 최대금액은?

### 풀이

**1단계 — 비정상 확률 역산**
- 조사 안 함: 70,000 × P(비정상) = 21,000 → **P(비정상) = 0.3**, P(정상) = 0.7

**2단계 — 교정비용 역산**
- 조사함: 10,000 + 교정비용 × 0.3 = 19,000 → **교정비용 = 30,000**

**3단계 — 완전정보 하 최적행동의 기대비용**
- 정상(0.7): 조사 안 함 → 비용 0
- 비정상(0.3): 조사 + 교정 → 10,000 + 30,000 = 40,000
- 기대비용 = 0.7×0 + 0.3×40,000 = **12,000**

**4단계 — EVPI**
- 현재 최선 = min(19,000, 21,000) = 19,000
- EVPI = 19,000 − 12,000 = **7,000**

### 정답
**③ 7,000**

**함정** — "완전정보의 대가" = (현 최선의 기대비용) − (완전정보 하 기대비용). 조사비용 자체 10,000과 헷갈리지 않아야 한다.

## [문제 37] 보조부문 외주 의사결정 — S1 폐지 효과

> **[문제]**
> S1(전력, 변동원가 100/kW)은 1,000kW를 공급(S2 200, A 500, B 300), S2(서비스, 변동원가 80/시간)는 1,000시간을 공급(S1 300, A 450, B 250). 한국이 전력을 120/kW에 공급하겠다고 제안. S1을 폐지하고 전력을 전량 한국에서 받으면 이익 증가액은?

### 풀이

**1단계 — S1 폐지로 절감되는 변동원가**
- S1 자체 변동원가: 1,000kW × 100 = **100,000**
- S2가 S1에 공급하던 300시간 분 변동원가: 300 × 80 = **24,000**
- 절감 합계 = **124,000**

**2단계 — 한국으로부터 구매할 전력량**
- 제조부문 A·B 수요: 500 + 300 = 800kW
- S2도 운영에 200kW 필요(기존 S1에서 수령) → **총 1,000kW**
- 구매비용 = 1,000 × 120 = **120,000**

**3단계 — 이익 증가**
- 124,000 − 120,000 = **4,000**

### 정답
**① 4,000**

**함정** — 한국 구매량을 800kW로만 잡으면 28,000이 나와 보기에 없다. S2는 폐지되지 않고 계속 운영되므로, S2가 사용하던 200kW도 한국에서 구매해야 한다는 점이 결정적이다.

## [문제 38] 제약자원 + 특별주문 의사결정

> **[문제]**
> 특수기계 10,000시간. A(단가 400, 변동 160, 2시간, 수요 3,000), B(500/200/3시간/1,000), C(700/380/4시간/500). 최적 생산계획 직후 한국이 제품 A를 단위당 360에 800단위 주문. 이익 증가액은?

### 풀이

**1단계 — 시간당 공헌이익 순위**
- A: (400−160)/2 = 120
- B: (500−200)/3 = 100
- C: (700−380)/4 = 80
- 순위 **A > B > C**

**2단계 — 최적 생산계획 (10,000시간)**
- A 3,000단위 × 2 = 6,000시간
- B 1,000단위 × 3 = 3,000시간
- 잔여 1,000시간 → C 250단위 (수요 500단위 대비 250 부족)

**3단계 — 특별주문 분석**
- 필요 시간: 800단위 × 2 = 1,600시간
- 특별주문 단위당 공헌이익: 360 − 160 = 200
- 특별주문 총 공헌이익: 800 × 200 = **160,000**

**4단계 — 포기해야 할 공헌이익 (시간당 공헌이익 낮은 제품부터)**
- C 전량 250단위(1,000시간) 포기: 250 × (700−380) = 250 × 320 = 80,000
- 남은 600시간 → B에서 600/3 = 200단위 포기: 200 × 300 = 60,000
- 포기 합계 = **140,000**

**5단계 — 이익 증가**
- 160,000 − 140,000 = **20,000**

### 정답
**⑤ 20,000**

**함정** — 단순히 A의 추가 공헌이익만 계산하거나 C부터 포기하는 것까지만 보고 80,000을 빼면 80,000이 나오지만, **시간이 모자라 B도 200단위 포기**해야 한다는 점이 핵심이다.

## [문제 39] 계단형 고정원가 — 증가분과 최대이익

> **[문제]**
> 단가 200, 변동원가 150. 1~1,000단위 구간 BEP = 840단위, 1,001~2,500단위 구간 BEP = 2,400단위. 두 구간 간 증가 고정원가(a)와 달성 가능한 최대이익(b)은?

### 풀이

**1단계 — 단위당 공헌이익**
- 200 − 150 = 50

**2단계 — 구간별 고정원가**
- 구간1 고정원가 = 840 × 50 = 42,000
- 구간2 고정원가 = 2,400 × 50 = 120,000
- **(a) 증가 고정원가 = 120,000 − 42,000 = 78,000**

**3단계 — 구간별 최대이익**
- 구간1 최대(1,000단위): 1,000×50 − 42,000 = **8,000**
- 구간2 최대(2,500단위): 2,500×50 − 120,000 = **5,000**
- **(b) 최대이익 = max(8,000, 5,000) = 8,000**

### 정답
**② (a) 78,000, (b) 8,000**

**함정** — "두번째 구간이 더 많이 팔리니까 이익도 더 크다"고 단정하면 ③ (b)=5,000을 고르게 된다. **계단형 고정원가가 크게 증가하면 더 큰 구간의 최대이익이 오히려 더 작을 수 있다**는 점이 출제 의도다.

## [문제 40] 내부대체가격 — 최소대체가격

> **[문제]**
> A사업부 최대생산능력 4,000단위, 단위당 변동원가 600, 외부 단위당 1,000에 3,000단위 판매 예상. B사업부가 1,600단위 내부대체 요청, 내부대체분은 변동원가가 단위당 50 감소. 1,600단위 전량대체 시 단위당 최소대체가격은?

### 풀이

**1단계 — A 사업부 여유능력 확인**
- 여유능력 = 4,000 − 3,000 = 1,000단위 → 1,600단위 요청 중 **600단위는 외부판매 포기 필요**

**2단계 — 1,600단위 총 증분원가**
- 내부대체 단위당 변동원가 = 600 − 50 = 550
- 변동원가: 1,600 × 550 = **880,000**
- 기회비용(외부판매 포기 600단위 × 외부 공헌이익 400) = 600 × (1,000−600) = **240,000**

  ※ 기회비용 계산 시 외부판매 공헌이익은 **원래 변동원가 600** 기준 (50 감소는 내부대체분에만 적용)

- 총 증분원가 = 880,000 + 240,000 = **1,120,000**

**3단계 — 단위당 최소대체가격**
- 1,120,000 / 1,600 = **700**

### 정답
**③ 700**

**함정** — 변동원가가 50 감소한다고 모든 1,600단위에 대해 공헌이익도 350(=1,000−650)으로 잡으면 기회비용을 잘못 계산한다. **외부판매 포기분의 공헌이익은 원래 400 그대로** 사용해야 한다. 또 여유능력 1,000단위만 대체한다고 가정해 변동원가만 보면 ⑤ 550이 나와 버리는데, 600단위에 대한 외부판매 기회비용을 반드시 가산해야 한다.
