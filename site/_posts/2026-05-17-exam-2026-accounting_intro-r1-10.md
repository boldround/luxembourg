2026년 제63회 세무사 1차 회계학개론 1-10번은 K-IFRS 전 영역에서 빈출되는 핵심 쟁점이 골고루 출제되었다. 확정급여제도(월할 순이자), 간접법 현금흐름표(이자·법인세 영업분류), 가중평균소매재고법, 이동평균법 정상감모 산정, 건설계약 손실예상, 고객충성제도 포인트, 유형자산 손상과 회복 등 계산형이 8문항, 진술형 옳지않은 것 찾기가 3문항 비중을 차지하며 난이도는 중상으로 평가된다.

## [문제 1] 확정급여제도가 당기순이익에 미치는 영향

> **[문제]**
> 20×1년 초 확정급여채무 ₩400,000, 사외적립자산 ₩300,000. 당기근무원가 ₩200,000, 4/1 퇴직급여 ₩120,000 지급, 7/1 ₩160,000 출연. 할인율 10%, 보험수리적가정 변동 없음. 당기순이익에 미치는 영향은?

### 풀이

**1단계 — 확정급여채무 이자비용 (월할)**
- 기초 400,000 × 10% × 12/12 = 40,000
- 4/1 지급액 효과: -120,000 × 10% × 9/12 = -9,000
- 이자비용 = **31,000**

**2단계 — 사외적립자산 이자수익 (월할)**
- 기초 300,000 × 10% × 12/12 = 30,000
- 4/1 지급 효과: -120,000 × 10% × 9/12 = -9,000
- 7/1 출연 효과: +160,000 × 10% × 6/12 = +8,000
- 이자수익 = **29,000**

**3단계 — 순이자비용**
- 31,000 - 29,000 = **2,000**

**4단계 — 당기순이익 영향**
- 퇴직급여원가(NI) = 당기근무원가 + 순이자비용 = 200,000 + 2,000 = **202,000 감소**
- (보험수리적가정 변동 없음 → 재측정요소 = 0, 모두 OCI로만 가는 항목 없음)

### 정답
**④ ₩202,000 감소**

## [문제 2] 간접법 영업활동 순현금유입

> **[문제]**
> 당기순이익 70,000, 법인세비용 30,000, 이자비용 27,000, 감가상각비 40,000. 이자지급·법인세납부는 영업활동. 운전자본 증감 자료 주어짐.

### 풀이

이자비용·법인세비용은 손익에 이미 반영된 **현금성 비용**이므로 간접법에서는 역가산하지 않고, 관련 운전자본(선급이자, 이연법인세자산, 당기법인세부채) 증감만 조정한다.

**1단계 — 비현금 항목 가산**
- 당기순이익 70,000 + 감가상각비 40,000 = **110,000**

**2단계 — 운전자본 조정**

| 항목 | 증감 | 조정 |
|---|---|---|
| 매출채권 증가 | +20,000 | -20,000 |
| 선급이자 증가 | +3,000 | -3,000 |
| 재고자산 감소 | -10,000 | +10,000 |
| 이연법인세자산 증가 | +7,000 | -7,000 |
| 매입채무 증가 | +30,000 | +30,000 |
| 선수금 감소 | -10,000 | -10,000 |
| 미지급급여 증가 | +20,000 | +20,000 |
| 당기법인세부채 감소 | -5,000 | -5,000 |
| **합계** | | **+15,000** |

**3단계 — 영업활동 순현금유입**
- 110,000 + 15,000 = **125,000**

### 정답
**② ₩125,000**

## [문제 3] 가중평균소매재고법 — 기초재고원가 역산

> **[문제]**
> 원가기준 가중평균소매재고법. 기말재고 ₩56,000일 때 기초재고원가는?

### 풀이

**1단계 — 판매가능재고(판매가)**
- 기초 200,000 + 총매입 712,000 + 순인상 35,000 - 순인하 25,000 - 비정상파손 22,000 = **900,000**

**2단계 — 기말재고(판매가)**
- 판매가능 - 순매출 - 종업원할인 - 정상파손
- = 900,000 - (830,000 - 30,000) - 15,000 - 5,000 = **80,000**

**3단계 — 원가율 (가중평균)**
- 기말재고원가 = 기말재고판매가 × 원가율 → 56,000 = 80,000 × 원가율
- 원가율 = **0.7**

**4단계 — 판매가능재고원가 역산**
- 판매가능재고원가 = 900,000 × 0.7 = **630,000**
- 기초 + 순매입원가(530,000 - 20,000 - 14,000) = 630,000
- 기초 + 496,000 = 630,000
- **기초재고원가 = 134,000**

### 정답
**③ ₩134,000**

## [문제 4] 이동평균법 + 정상감모수량

> **[문제]**
> 매입·매출 단가가 모두 ₩200으로 동일. 기말 NRV ₩180, 실제수량 380개. 매출원가 ₩108,000일 때 정상감모수량은?

### 풀이

**1단계 — 장부재고**
- 모든 단가가 200으로 동일 → 이동평균단가 200 유지
- 매입 900개 - 매출 500개 = **장부 400개, 단가 200, 합 80,000**

**2단계 — 총감모수량**
- 장부 400 - 실제 380 = **20개**

**3단계 — 평가손실 (실제수량 기준)**
- 380개 × (200 - 180) = **7,600**

**4단계 — 매출원가 구성식**
- 판매분 500개 × 200 = 100,000
- 정상감모 X개 × 200 = 200X
- 평가손실 = 7,600
- 매출원가 = 100,000 + 200X + 7,600 = 108,000
- 200X = 400 → **X = 2개**

### 정답
**① 2개**

## [문제 5] 법인세회계 (옳지 않은 것)

> **[문제]**
> 법인세회계에 관한 설명으로 옳지 않은 것은?

### 풀이

⑤번이 결정적 오류: "미사용 세무상결손금과 세액공제"가 사용될 수 있는 미래과세소득 발생가능성이 높으면 그 범위 안에서 **이연법인세자산**을 인식해야 한다(K-IFRS 1012호 문단 34). 이연법인세부채는 가산할 일시적차이에 대해 인식하는 항목이므로 결손금·세액공제 이월과 결합되지 않는다. ①~④는 모두 K-IFRS 1012호의 측정·인식 기준에 부합한다.

### 정답
**⑤** (이연법인세부채 → **이연법인세자산**)

## [문제 6] 공정가치측정

> **[문제]**
> 공정가치측정에 관한 설명으로 옳은 것은?

### 풀이

③번이 옳다. K-IFRS 1113호는 관측 가능한 시장이 없어도 시장참여자 관점에서 측정일에 거래가 이루어질 것으로 **가정**하여 공정가치를 측정하도록 규정한다. ①은 주된 시장이 있으면 다른 시장이 더 유리해도 주된 시장 가격이 우선이며, ②는 비금융자산의 최고최선 사용은 반드시 시장참여자 관점에서 고려해야 하고, ④는 주된 시장 가격에 **거래원가를 조정하지 않으며**, ⑤는 부채 공정가치 측정 시 신용위험뿐 아니라 의무 이행/미이행 가능성에 영향을 주는 모든 요소를 고려해야 한다.

### 정답
**③**

## [문제 7] 환율변동효과 (옳지 않은 것)

> **[문제]**
> 환율변동효과에 관한 설명으로 옳지 않은 것은?

### 풀이

②번이 틀렸다. K-IFRS 1021호 문단 30: 비화폐성항목에서 생긴 손익을 **기타포괄손익으로 인식하는 경우 그 손익의 환율변동효과도 기타포괄손익으로** 인식한다. 당기손익으로 인식하는 경우에만 환율변동효과도 당기손익이다. ①(기능통화 변경 시 전진적용), ③(거래일 현물환율 적용), ④(화폐성=마감환율, 역사적원가 비화폐성=거래일환율), ⑤(표시통화와 기능통화가 다른 경우 명칭·사유 공시)는 모두 옳다.

### 정답
**②**

## [문제 8] 건설계약 공사손실 (20×2년)

> **[문제]**
> 총계약수익 ₩650,000, 발생원가 200/220/300, 추가예정원가 300/280/0. 20×2년 공사손실은?

### 풀이

**1단계 — 20×1년 누계손익**
- 진행률 = 200/(200+300) = 40%
- 계약수익 누계 = 650,000 × 40% = 260,000
- 계약손익 누계 = 260,000 - 200,000 = **+60,000**

**2단계 — 20×2년 누계 진행률 기준**
- 누적원가 = 420,000, 총예정원가 = 420,000 + 280,000 = 700,000
- 진행률 = 420/700 = 60%
- 계약수익 누계 = 650,000 × 60% = 390,000
- 진행률 기준 손익 누계 = 390,000 - 420,000 = **-30,000**

**3단계 — 미진행분 예상손실 (전액 즉시 인식)**
- 총계약손실 = 650,000 - 700,000 = -50,000
- 미진행분 손실 = -50,000 - (-30,000) = **-20,000** 즉시 인식

**4단계 — 20×2년 당기 공사손익**
- 20×2년 누계 인식손익 = -30,000 + (-20,000) = -50,000
- 20×1년 인식이익 = +60,000
- 당기 손익 = -50,000 - 60,000 = **-110,000 (공사손실)**

### 정답
**④ ₩110,000**

## [문제 9] 고객충성제도 포인트 (20×2년 인식수익)

> **[문제]**
> 총판매 ₩1,000,000, 500,000 포인트 부여. 제품 SSP ₩1,000,000, 포인트 SSP ₩250,000. 20×1년 말 100,000 교환·예상 250,000, 20×2년 말 누적 180,000 교환·예상 300,000.

### 풀이

**1단계 — 거래가격 배분**
- 포인트 배분액 = 1,000,000 × (250,000 / 1,250,000) = **200,000**

**2단계 — 20×1년 누적 수익**
- 200,000 × (100,000 / 250,000) = **80,000**

**3단계 — 20×2년 누적 수익**
- 200,000 × (180,000 / 300,000) = **120,000**

**4단계 — 20×2년 인식 수익**
- 120,000 - 80,000 = **40,000**

### 정답
**① ₩40,000**

## [문제 10] 유형자산 손상과 회복

> **[문제]**
> 20×1.7.1 취득(원가 1,000,000, 내용연수 5년, 잔존 100,000, 연수합계법). 20×3년 초 잔존내용연수 3년으로 변경. 20×2년 말 손상, 20×4년 말 회복. 20×4년 당기순이익 영향은?

### 풀이

**1단계 — 20×2년 말 손상 전 장부금액**
- 1차연도 상각액 = 900,000 × 5/15 = 300,000
- 20×1년(6개월): 300,000 × 6/12 = 150,000
- 20×2년: 300,000 × 6/12 + (900,000 × 4/15) × 6/12 = 150,000 + 120,000 = 270,000
- 손상 전 장부 = 1,000,000 - 420,000 = **580,000**

**2단계 — 20×2년 말 손상**
- 회수가능액 = max(180,000, 190,000) = 190,000
- 손상차손 = 580,000 - 190,000 = 390,000
- **20×2년 말 장부 = 190,000**

**3단계 — 20×3년 초 추정변경 후 20×3·20×4년 상각**
- 감가상각대상 = 190,000 - 100,000 = 90,000, 연수합계 = 3+2+1 = 6
- 20×3년: 90,000 × 3/6 = 45,000 → 말 장부 145,000
- 20×4년: 90,000 × 2/6 = **30,000** → 회복 전 장부 = **115,000**

**4단계 — 20×4년 말 손상회복 한도**
- 회수가능액 = max(145,000, 135,000) = 145,000
- 손상되지 않았다면(추정변경은 그대로 반영) 20×4년 말 장부 = 180,000 [확인 필요: 추정변경 시점·반영 견해에 따라 상한 달라질 수 있으나 본 사례에서는 회수가능액 145,000이 더 작아 한도 = 145,000]
- 회복 후 장부 = min(145,000, 한도) = **145,000**
- 손상차손환입 = 145,000 - 115,000 = **+30,000**

**5단계 — 20×4년 당기순이익 영향**
- 감가상각비 -30,000 + 손상차손환입 +30,000 = **0**

### 정답
**① 영향 없음**
