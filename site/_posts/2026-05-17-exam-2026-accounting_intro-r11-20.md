## [문제 11] 차입원가 자본화 — 20×2년도 자본화액

> **[문제]**
> (주)세무는 20×1.7.1.~20×2.12.31. 적격자산인 영업지점 건물을 신축하였다. 지출액은 20×1.7.1. ₩100,000 / 10.1. ₩200,000(이 중 ₩100,000은 같은 날 수령한 정부보조금으로 지출) / 12.1. ₩300,000 / 20×2.7.1. ₩100,000이다. 특정차입금 ₩100,000(20×1.7.1.~12.31., 8%) 중 ₩20,000은 20×1.7.1.~9.30. 3개월간 연 10% 금융상품에 일시 운용. 일반차입금 A는 ₩500,000(20×1.1.1.~20×2.12.31., 10%), B는 ₩1,000,000(20×1.7.1.~20×2.6.30., 6%). 자본화한 차입원가는 연평균지출액 계산 시 포함하고, 정부보조금은 자산 장부금액에서 차감하는 방법.

### 풀이

**1단계 — 20×1년 자본화 차입원가 (20×2년 연평균지출액에 가산해야 하므로 선행 계산)**

연평균지출액(보조금 차감 후 실 지출 기준):
- 100,000 × 6/12 = 50,000
- (200,000 − 100,000) × 3/12 = 25,000
- 300,000 × 1/12 = 25,000
- 합계 = **100,000**

특정차입금 사용분 평균(일시운용액 차감):
- 100,000 × 6/12 − 20,000 × 3/12 = 50,000 − 5,000 = **45,000**

특정차입금 자본화액: 100,000 × 8% × 6/12 − 20,000 × 10% × 3/12 = 4,000 − 500 = **3,500**

일반차입금 가중평균이자율:
- A 이자 500,000 × 10% = 50,000 / 평균차입 500,000
- B 이자 1,000,000 × 6% × 6/12 = 30,000 / 평균차입 500,000
- 가중평균 = 80,000 / 1,000,000 = **8%**

일반차입금 자본화액 = (100,000 − 45,000) × 8% = **4,400** (한도 80,000 이내)

20×1년 자본화 총액 = 3,500 + 4,400 = **₩7,900**

**2단계 — 20×2년 연평균지출액 (자본화액 포함)**

20×1년 말 누적지출 = 100,000 + 100,000 + 300,000 + 7,900 = 507,900

- 507,900 × 12/12 = 507,900
- 100,000 × 6/12 = 50,000
- 합계 = **557,900**

**3단계 — 20×2년 차입원가 자본화**

특정차입금은 20×1.12.31.에 상환되어 20×2년 잔액 없음. 일반차입금 가중평균이자율(20×2년):
- A 이자 50,000 / 평균 500,000
- B 이자 1,000,000 × 6% × 6/12 = 30,000 / 평균 500,000
- 가중평균 = 80,000 / 1,000,000 = **8%**

자본화액 = 557,900 × 8% = **44,632** (한도 80,000 이내)

### 정답
**① ₩44,632** — 정부보조금은 지출액에서 차감, 전년도 자본화액(7,900)을 누적지출액에 포함하는 두 가지 처리를 모두 잡아야 한다.

## [문제 12] 자기주식 거래 후 자본총계

> **[문제]**
> 기초 자본총계 ₩400,000(보통주자본금 100,000 + 주발초 200,000 + 이익잉여금 100,000). 자기주식 거래: 2/2 60주 @600 취득 / 3/3 20주 @700 처분 / 4/4 10주 @500 처분 / 9/15 20주 @400 처분 / 10/30 10주 소각. 당기순이익 ₩50,000. 선입선출 원가법.

### 풀이

자기주식 거래의 자본총계 영향은 **현금 유출입의 순효과**로 계산하면 되며, 소각은 자본 내 재분류에 불과해 자본총계에 영향 없다.

- 취득: −60주 × 600 = **−36,000**
- 처분: 20×700 + 10×500 + 20×400 = 14,000 + 5,000 + 8,000 = **+27,000**
- 소각: 자본총계 영향 **0**
- 당기순이익: **+50,000**

기말 자본총계 = 400,000 − 36,000 + 27,000 + 50,000 = **₩441,000**

### 정답
**⑤ ₩441,000** — 함정은 자기주식처분손익(자본잉여금/결손)과 소각손익(감자차익/차손)을 따로 계산하려는 시도. 자본총계만 묻는 문제는 순현금흐름 + 당기순이익만 더하면 끝난다.

## [문제 13] 개발활동에 해당하는 것

> **[문제]**
> ㄱ. 새로운 기술과 관련된 공구, 지그, 주형, 금형 등을 설계하는 활동 / ㄴ. 최종 선정안을 설계·제작·시험하는 활동 / ㄷ. 여러 대체안을 탐색하는 활동 / ㄹ. 여러 대체안을 제안·설계·평가·최종선택하는 활동

### 풀이

K-IFRS 1038(무형자산) 문단 56·59의 예시 구분:
- ㄱ → 신기술 공구·지그·금형 설계: **개발활동** (문단 59)
- ㄴ → 최종 선정안 설계·제작·시험: **개발활동** (문단 59)
- ㄷ → 대체안 **탐색**: **연구활동** (문단 56)
- ㄹ → 대체안 제안·설계·평가·**최종선택**: **연구활동** (문단 56) — "최종선택"은 개발이 아니라 연구의 마지막 단계로 분류

### 정답
**① ㄱ, ㄴ** — 함정은 ㄹ의 "최종선택"이라는 단어 때문에 개발로 오인하는 것. 대체안의 평가·선택은 연구, 선정된 안의 설계·시제품 제작이 개발이다.

## [문제 14] 투자부동산 — 옳지 않은 것

### 풀이

② "공정가치 측정이 어려워지면 원가모형을 적용한다" → **틀림**. K-IFRS 1040 문단 55는 일단 공정가치모형을 선택하면 비교 가능한 시장 거래가 줄어들고 시장가격 정보를 얻기 어렵게 되더라도 처분·자가사용대체·금융리스대체 전까지는 **공정가치모형을 계속 적용**해야 함을 규정한다. 원가모형으로의 변경은 인정되지 않는다.

①(자가경영 호텔은 자가사용), ③(재고자산→공정가치 투자부동산 대체 시 차액 당기손익, 문단 63), ④(시장가격 임차료를 받더라도 종업원 사용 부동산은 자가사용, 문단 9), ⑤(후불 취득 시 현금가격상당액 + 차액은 신용기간 이자비용)는 모두 옳다.

### 정답
**②** — 공정가치모형은 "한 번 선택하면 끝"이라는 일관성 원칙을 기억할 것.

## [문제 15] 농림어업 — 옳지 않은 것

### 풀이

② "수확물은 최초인식 시 공정가치에서 처분부대원가를 **가산**한 금액으로 인식" → **틀림**. K-IFRS 1041 문단 13은 수확물은 수확 시점의 **공정가치에서 처분부대원가를 차감**(공정가치 − 처분부대원가)한 금액으로 측정한다고 규정.

①(생물자산 최초인식 공정가치 신뢰성 측정 불가 시 원가모형), ③(한해살이 작물은 생산용식물 제외, 문단 5A), ④(목재 등 수확물로 수확하기 위한 식물은 생산용식물 제외, 문단 5B), ⑤(원양어업·천연림벌채 등 관리되지 않은 자원 수확은 농림어업 활동 아님, 문단 6)는 모두 옳다.

### 정답
**②** — "가산"과 "차감" 한 글자 차이 함정. 측정 공식은 무조건 (FV − 처분부대원가).

## [문제 16] 희석주당이익 — 보통주 평균시가

> **[문제]**
> 기초 보통주 1,000주, 20×1.4.1. 무상증자 20%. 미행사 신주인수권 600개(1개당 1주, 행사가 ₩3,000). 당기순이익 ₩1,200,000. 희석 EPS ₩800.

### 풀이

**1단계 — 가중평균유통보통주식수**

무상증자는 기초로 소급 적용: 1,000주 × 1.2 = **1,200주**

**2단계 — 자기주식법으로 잠재적 보통주식수 산정**

신주인수권 행사 → 600주 발행, 현금 600 × 3,000 = 1,800,000 수취 → 평균시가 P로 1,800,000/P주를 자기주식 취득.

증가 주식수 = 600 − 1,800,000/P = 600(1 − 3,000/P)

**3단계 — 희석 EPS 방정식**

$$\frac{1,200,000}{1,200 + 600(1 - 3,000/P)} = 800$$

1,200 + 600 − 1,800,000/P = 1,500
1,800,000/P = 300
**P = 6,000**

### 정답
**④ ₩6,000** — 함정은 무상증자 효과를 가중평균에 월할 적용하는 것. 무상증자·주식분할은 무조건 기초 소급.

## [문제 17] 연속상환사채 — 조기상환 후 20×3년 손익효과

> **[문제]**
> 액면 ₩1,500,000, 표시 5%, 매년 ₩500,000씩 연속상환(20×1~20×3 12월말). 시장이자율 6%, 사채발행비 ₩26,422. 20×1년 이자비용 ₩101,243. 20×3.1.1. 60%를 ₩270,000에 조기상환, 잔여 40%는 만기상환.

### 풀이

**1단계 — 유효이자율 확정**

발행가액(사발비 차감 전) = 575,000 × 0.9434 + 550,000 × 0.8900 + 525,000 × 0.8396 = 1,472,745
사발비 차감 후 = 1,472,745 − 26,422 = **1,446,323**

이자비용 검증: 1,446,323 × 7% = 101,243 ✓ → **유효이자율 = 7%**

**2단계 — 장부금액 흐름**

- 20×1.12.31. BV = 1,446,323 + 101,243 − 575,000 = **972,566**
- 20×2년 이자비용 = 972,566 × 7% ≈ 68,080
- 20×2.12.31. BV = 972,566 + 68,080 − 550,000 = **490,646**

**3단계 — 20×3년 P/L 영향**

60% 조기상환:
- 60% 장부금액 = 490,646 × 0.6 = 294,388
- 상환가액 = 270,000
- 조기상환이익 = **+24,388**

40% 만기보유:
- 40% 장부금액 = 490,646 × 0.4 = 196,258
- 이자비용 = 196,258 × 7% = **13,738**

20×3년 당기순이익 영향 = +24,388 − 13,738 = **+₩10,650**

### 정답
**③ ₩10,650 증가** — 함정은 ⑤(₩24,388)로 조기상환이익만 잡고 잔여 40% 이자비용을 누락하는 것. 60/40 안분을 끝까지 유지해야 한다.

## [문제 18] 회계정책·회계추정치 변경과 오류 — 옳지 않은 것

### 풀이

② "전기오류의 수정은 오류가 발견된 기간의 당기손익으로 보고한다" → **틀림**. K-IFRS 1008 문단 42는 중요한 전기오류는 그 오류가 발견된 이후 최초로 발행을 승인하는 재무제표에 **비교표시되는 과거기간의 금액을 재작성**(소급재작성)하여 수정한다고 규정한다. 당기손익으로 보고하지 않는다.

①(추정의 근거가 변동한 경우 추정변경은 오류수정 아님), ③(측정기준 변경은 정책변경, 구분 어려우면 추정변경, 문단 35), ④(K-IFRS 조기적용은 자발적 정책변경 제외, 문단 14·19), ⑤(과거 누적효과 실무 결정 불가 시 가장 이른 날부터 전진 적용 — 문단 45 기준서 원문)는 모두 옳다.

### 정답
**②** — "오류 = 소급재작성, 추정변경 = 전진법"이 대원칙. 당기손익 처리는 추정변경에만 적용된다.

## [문제 19] 사채 조건변경 — 실질적 조건변경

> **[문제]**
> 액면 1,000,000, 표시 8%, 만기 3년(20×3.12.31.), 발행 시 시장이자율 10%. 20×1년 이자 정상 지급, 20×2.1.1. 무이자·만기 20×5.12.31. 원금 일시상환으로 조건변경. 20×2년 초 시장이자율 12%.

### 풀이

**1단계 — 조건변경 직전 장부금액**

발행가액 = 1,000,000 × 0.7513 + 80,000 × 2.4869 = 751,300 + 198,952 = **950,252**
20×1.12.31. BV = 950,252 × 1.10 − 80,000 = **965,277**

**2단계 — 실질적 조건변경 여부 (10% 기준)**

변경 후 현금흐름의 PV(기존 유효이자율 10% 적용) = 1,000,000 × 0.6830 = 683,000

차이율 = (965,277 − 683,000) / 965,277 ≈ **29.2%** > 10% → **실질적 조건변경 (기존 부채 제거 + 신규 부채 인식)**

**3단계 — 신규 부채 측정 (변경시점 시장이자율 12% 적용)**

신규 부채 PV = 1,000,000 × 0.6355 = **635,500**

조건변경이익 = 965,277 − 635,500 = **+329,777**

**4단계 — 20×2년 이자비용**

신규 부채는 12% 유효이자율 적용: 635,500 × 12% = **76,260**

**20×2년 당기순이익 영향** = +329,777 − 76,260 = **+₩253,517**

### 정답
**④ ₩253,517 증가** — 함정은 ①·②처럼 실질적 변경이 아니라고 보고 기존 유효이자율(10%)로 계속 처리하는 것. 10% 테스트를 통과(29% 차이)했으므로 부채 교체 + 새 시장이자율(12%) 적용이 핵심.

## [문제 20] 전환사채 — 옳지 않은 것

### 풀이

③ "조기 전환을 유도하기 위한 조건변경 시 변경된 조건의 공정가치와 원래 조건의 공정가치의 차이는 **기타포괄손익**으로 인식" → **틀림**. K-IFRS 1032 문단 AG35는 조기 전환을 유도하는 조건변경(induced conversion) 시 추가지급분의 공정가치를 **당기손익(비용)**으로 인식하도록 규정한다.

①(만기 전환 시 자본 대체, 손익 없음), ②(조기 상환 시 지급 대가와 거래원가를 부채요소와 자본요소에 배분), ④(부채요소는 동일조건·동일신용·동일현금흐름의 비전환채무 시장이자율로 할인), ⑤(외가격 전환권도 시간가치가 존재)는 모두 옳다.

### 정답
**③** — 유도전환(induced conversion)의 추가대가는 **비용(당기손익)**이지 OCI가 아니다. 자본거래로 보지 않는 점이 핵심.
