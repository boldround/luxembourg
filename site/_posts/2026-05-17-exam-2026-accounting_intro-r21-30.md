회계학개론 21~30번은 **중급회계 후반(확정급여·금융자산 손상·지분법·위험회피)과 원가관리회계(결합·ABC·종합·표준·정상원가)**가 절반씩 배치된 구간이다. 22번(채무상품 손상+FVOCI 누계액), 27번(가중평균법 하 정상공손 기준 정상품 산정)이 함정 난도가 높고, 나머지는 정형화된 패턴이라 공식만 잡으면 풀린다.

## [문제 21] 확정급여제도 — 당기순이익 영향

**정답 ④ ₩202,000 감소**

이자비용 = 400,000×10% − 120,000×10%×9/12 = 40,000 − 9,000 = **31,000**, 이자수익 = 300,000×10% − 120,000×10%×9/12 + 160,000×10%×6/12 = 30,000 − 9,000 + 8,000 = **29,000**, 순이자비용 = 2,000. 여기에 당기근무원가 200,000을 합하여 총 **202,000 감소**. 함정: 기여금 출연(7/1)과 퇴직급여 지급(4/1)에 대한 이자 가감을 빠뜨리면 ③ 200,000 감소로 오답을 고르게 된다.

## [문제 22] 채무상품 손상 — AC vs FVOCI 분류

**정답 ④ (옳지 않은 설명)**

20×1년 이자수익 = 951,980×12% = **114,238** (①✓), 손상 후 PV = 900,000×0.7972 = **717,480**, 손상차손 = 966,218 − 717,480 = 248,738 → FVOCI도 손상은 당기손익이므로 NI 영향 = 114,238 − 248,738 = **−134,500** (②✓). 20×2년 회복 후 PV = 970,000×0.8929 = 866,113, 이자수익 86,098 + 환입 62,535 = **148,633** (③✓). 자본 변동 = NI(−134,500) + OCI(680,000 − 717,480 = −37,480) = **−171,980** (⑤✓). 따라서 OCI 누계액은 −37,480이지 −116,215가 아니므로 **④가 틀린 설명**이다.

## [문제 23] 지분법 — 하향거래 미실현이익

**정답 ⑤ ₩462,800**

미실현이익 = (50,000−35,000) × 20,000/50,000 = 6,000, 투자자 지분 = 6,000×20% = **1,200**. 지분법이익 = 200,000×20% − 1,200 = **38,800**, 지분법자본변동(OCI) = 20,000×20% = **4,000**. 장부금액 = 420,000 + 38,800 + 4,000 = **462,800**. 함정: 영업권 20,000은 손상되지 않으므로 별도 조정 없음, 또한 하향거래 미실현이익은 판매자(투자자) 지분만큼만 제거(지분율 100%가 아님)에 주의.

## [문제 24] 위험회피수단 지정 가능성

**정답 ⑤**

K-IFRS 1109호 6.2.1~6.2.3에 따라 ① FVOCI 선택 지분상품의 외화위험부분은 위험회피수단 지정 불가(공정가치 변동을 OCI로 표시하기로 한 지분상품 자체가 위험회피수단 대상에서 제외), ② 자기지분상품은 자산·부채가 아니므로 지정 불가, ③ 분리 회계처리하지 않는 내재파생상품은 별도로 지정 불가, ④ 비파생금융부채는 외화위험회피만 지정 가능(FVPL 지정 부채라도 일반론). 반면 ⑤는 1109호 6.2.3에 따라 위험회피수단으로 지정하는 경우 **전체 또는 비례적 부분**만 지정 가능하므로 옳다.

## [문제 25] 결합원가 — 순실현가치법

**정답 ① ₩58,800**

부산물 X의 NRV 4,000(=20×200)을 1공정 결합원가 100,000에서 차감 → **96,000을 A·F에 NRV로 배부**. A NRV = 100×1,600 = 160,000, F NRV = (150×1,000 − 10,000) + (200×800 − 20,000) − 40,000 = 140,000 + 140,000 − 40,000 = 240,000. F 배부 = 96,000 × 240/400 = **57,600**. F의 총원가 57,600 + 40,000 = 97,600을 B·C에 NRV(140,000:140,000)로 배부 → B 배부 = **48,800**. 최종 B 원가 = 48,800 + 10,000(3공정) = **58,800**. 함정: 2공정 결합원가 40,000을 NRV 계산에서 차감하지 않으면 배부비율이 틀어진다.

## [문제 26] 활동기준원가계산 — 작업준비 활동원가

**정답 ③ ₩176,800**

총 제조간접원가(예정배부 = 활동원가 총액) = (420,000+260,000)×110% = **748,000**. 재료가공 = (2,000×1.2 + 1,440×1.5) × 80 = 4,560 × 80 = **364,800**. 품질검사 = (2,000+1,440) × 60 = 3,440 × 60 = **206,400**. 작업준비 = 748,000 − 364,800 − 206,400 = **176,800**. 함정: 예정배부율 110%를 직접노무원가의 110%가 아닌 제조간접원가 합계의 110%로 오해하면 답이 빗나간다.

## [문제 27] 가중평균법 종합원가계산 — 정상공손 배분

**정답 ② ₩8,430**

총 투입 1,700 − 완성 1,300 − 기말 250 = **공손 150**. 검사시점 70%이고 기말재공품(60%)은 검사 미통과 → 정상공손 기준 합격품은 **당기 검사를 통과한 정상품 = 완성품 − 기초(이미 전기에 검사통과) = 1,300 − 300 = 1,000개**, 정상공손 = 1,000×5% = **50개**, 비정상공손 = 100개. 완성품원가 = 1,300×50 = 65,000 + 정상공손원가 50×70%×50 = 1,750 = **66,750**. 기말제품 = 5,520 + 66,750 − 63,840 = **8,430**. 함정: 가중평균법이라고 기초재공품까지 합격품에 포함시키면 정상공손이 65개로 늘어 완성품원가가 과대계상된다.

## [문제 28] 표준원가계산 — 실제 제조간접원가

**정답 ⑤ ₩91,800**

고정제조간접 표준배부율 = 52,000/(2,600×4) = **5/DLH**, 조업도차이 = 5 × (10,400 − 2,400×4) = 5×800 = 4,000 불리(✓). 능률차이 = 3.5 × (실제 DLH − 9,600) = 2,100 → 실제 DLH = **10,200시간**. 실제 제조간접원가 = 실제배부율 9 × 10,200 = **91,800**. 함정: 조업도차이는 고정만 계산, 능률차이는 변동만 계산해야 하므로 변동·고정 표준배부율을 헷갈리면 안 된다.

## [문제 29] 정상원가계산 — 배부차이 조정 후 매출원가

**정답 ④ ₩197,000**

제조간접원가 예정배부 = 42,000×140% = **58,800**, 실제 56,000 → 배부차이 = **2,800 과대배부**. 당기총제조원가 = 98,000 + 42,000 + 58,800 = 198,800, 당기제품제조원가 = 4,000 + 198,800 − 7,000 = 195,800, 매출원가(조정 전) = 16,000 + 195,800 − 12,000 = 199,800. 과대배부 차감 → **199,800 − 2,800 = 197,000**. 함정: 과대배부를 매출원가에 가산하면 ⑤ 199,800으로 오답을 고르기 쉽다(과대=원가가 많이 배부되었으므로 차감).

## [문제 30] 선입선출법 종합원가계산 — 제조간접원가 역산

**정답 ① ₩51,850**

전환원가 환산량 = 300×60% + (1,200−300)×100% + 350×60% = 180 + 900 + 210 = **1,290**. 당기 전환원가 = 1,290 × 65 = **83,850**. 제조간접원가 = 83,850 − 직접노무원가 32,000 = **51,850**. 함정: 기초재공품의 환산량을 (1−40%)=60%로 잡지 않고 100%로 잡거나, 가중평균법처럼 기초까지 1,200개에 포함시켜 100% 환산하면 답이 어긋난다.
