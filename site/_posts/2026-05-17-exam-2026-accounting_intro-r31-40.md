이번 회차 회계학개론 후반부(31~40)는 **재무회계 1문항(확정급여제도)**을 제외하면 모두 **원가관리회계**에서 출제되었다. ABC, CVP, EVA, 제한된 자원하 최적배합, 변동·전부원가차이, 외주 의사결정, 종합예산, 기대가치 의사결정까지 원가관리 전 영역이 골고루 다뤄졌으며, 계산 난이도는 평이하나 **세후현금흐름분기점·매입예산** 등 식 구성을 정확히 해야 풀리는 문항이 변별력을 가른다.

## [문제 31] 확정급여제도가 당기순이익에 미치는 영향

**정답: ④ ₩202,000 감소**

당기순이익 항목은 ① 당기근무원가 200,000과 ② 순확정급여부채에 대한 **순이자비용**이다. 확정급여채무 이자비용 = 400,000×10% − 120,000×10%×9/12 = 40,000 − 9,000 = 31,000, 사외적립자산 이자수익 = 300,000×10% − 120,000×10%×9/12 + 160,000×10%×6/12 = 30,000 − 9,000 + 8,000 = 29,000. 순이자비용 = 31,000 − 29,000 = 2,000이므로 당기순이익 영향 = −(200,000 + 2,000) = **−202,000**. 함정: 4/1 퇴직급여 지급과 7/1 출연을 월할로 가감해야 하며, 재측정요소(보험수리적 손익)는 기타포괄손익이므로 당기순이익에서 제외해야 한다.

## [문제 32] 활동기준원가계산 — 제품 A 배분원가

**정답: ① ₩180,810**

배치 수: A = 560/40 = 14배치, B = 1,200/50 = 24배치. ① **작업준비**: 총 (14+24)×2 = 76시간, 시간당 136,800/76 = 1,800 → A: 28×1,800 = 50,400. ② **조립**: A 252시간(560×0.45) + B 300시간(1,200×0.25) = 552시간, 시간당 276,000/552 = 500 → A: 252×500 = 126,000. ③ **품질검사**: A 7회·B 12회로 총 19시간, 시간당 11,970/19 = 630 → A: 7×630 = 4,410. 합계 = 50,400 + 126,000 + 4,410 = **180,810**. 함정: 분(分) 단위로 주어진 기계작업시간을 시(時)로 환산하고, 품질검사는 2배치당 1회임에 유의.

## [문제 33] 세후현금흐름분기점 판매수량

**정답: ① 200단위**

기존 BEP 300단위 × 단위당 공헌이익 = 고정원가 60,000 → 단위당 CM = 200. 세후순현금흐름 = (CM·Q − 고정원가)×(1−t) + 감가상각비 = 0 식을 세우면 (200Q − 60,000)×0.7 + 14,000 = 0 → 200Q − 60,000 = −20,000 → Q = **200단위**. 함정: 세후현금흐름분기점은 단순한 현금고정비BEP가 아니라 **감가상각비의 법인세 절감효과**를 반영한 식이어야 하며, 감가상각비 14,000은 비현금성 고정비로서 세후이익에 다시 가산된다.

## [문제 34] EVA 계산

**정답: ④ ₩90,000**

EVA = 세후영업이익 − 투자자본 × **가중평균자본비용**. 세후영업이익 = 200,000 × (1−0.25) = 150,000, 자본비용 = 500,000 × 12% = 60,000 → EVA = 150,000 − 60,000 = **90,000**. 함정: 최저필수수익률 10%는 잔여이익(RI) 계산용 미끼이며, EVA에서는 반드시 **가중평균자본비용(WACC)** 을 사용한다. 또한 영업이익에 (1−법인세율)을 곱한 세후영업이익을 사용해야 한다.

## [문제 35] 전부원가계산 vs 변동원가계산 — 기말재고수량

**정답: ⑤ 500단위**

영업개시연도이므로 기초재고 = 0. 전부원가 영업이익 − 변동원가 영업이익 = (기말재고 × 단위당 고정제조간접비) − 0 = 20,000. 단위당 고정제조간접비 = 40,000/1,000 = 40 → 기말재고수량 = 20,000/40 = **500단위**. 함정: 고정**판매관리비**는 두 방법 모두 기간비용이므로 차이에 영향을 주지 않으며, **고정제조간접비**만 변동·전부 차이를 만든다.

## [문제 36] 제한된 자원하의 최적 제품배합 — 최대 공헌이익

**정답: ② ₩830,000**

단위당 CM: A = 500−300 = 200, B = 1,000−500 = 500. **기계시간당 CM**: A = 200/1 = 200, B = 500/2 = 250 → B 우선 생산. B 최대 1,500단위 × 2시간 = 3,000시간, 잔여 400시간 → A 400단위. 최대 공헌이익 = 1,500×500 + 400×200 = 750,000 + 80,000 = **830,000**. 함정: 단위당 CM이 큰 B를 무조건 우선시키는 게 아니라 **제약자원 단위당 CM**으로 우선순위를 정해야 하며, 본 문제는 우연히 결론이 같다.

## [문제 37] 목표이익 달성 단위당 판매가격

**정답: ③ ₩132**

4월: 판매수량 = 16,000/100 = 160단위, 변동비 = 16,000×(1−0.25) = 12,000, 단위당 변동비 = 12,000/160 = 75, 고정비 = 20,000 − 12,000 = 8,000. 5월: 고정비 = 8,000 + 2,150 = 10,150, 세전목표이익 = 1,000/(1−0.2) = 1,250. (P−75)×200 − 10,150 = 1,250 → P − 75 = 57 → P = **132**. 함정: 세후이익을 (1−t)로 나누어 **세전이익**으로 환산해야 하며, 광고선전비는 5월에만 추가되는 고정비.

## [문제 38] 외주 의사결정 — 단위당 최대구입가격

**정답: ⑤ ₩950**

외부 구입 시 회피가능원가 = 변동제조원가 (300+200+100)×100 + 감독자급여 20,000(해고 가능) + 공통제조간접비 50,000×30% = 60,000 + 20,000 + 15,000 = 95,000. 단위당 최대구입가격 = 95,000/100 = **950**. 함정: 공통제조간접비 50,000 중 **30%만 회피 가능**하므로 15,000만 반영해야 하며, 70%는 외주해도 그대로 발생하는 비관련원가다.

## [문제 39] 매입대금 현금지출액 (8월)

**정답: ④ ₩10,125**

매출원가율 75% → 월별 매출원가: 7월 9,000, 8월 11,250, 9월 13,500. 월말재고 = 다음달 매출원가 × 10%. 매입액 = 당월매출원가 + 기말재고 − 기초재고. **7월 매입** = 9,000 + 1,125 − 900 = 9,225, **8월 매입** = 11,250 + 1,350 − 1,125 = 11,475. 8월 현금지출 = 8월매입×40% + 7월매입×60% = 11,475×0.4 + 9,225×0.6 = 4,590 + 5,535 = **10,125**. 함정: 8월 외상매입(60%)은 9월에 지급되므로 8월 현금지출에서 제외하고, 대신 7월 외상매입의 60%가 8월에 지급된다.

## [문제 40] 영업사원 급여방안 선택 — 기대영업이익

**정답: ⑤ ₩11,000**

**방안1**(고정급여 40,000): 단위당 CM = 2,000 − 1,000 = 1,000. 50단위 이익 = 50×1,000 − 5,000 − 40,000 = 5,000, 60단위 이익 = 60×1,000 − 45,000 = 15,000. 기대 = 5,000×0.4 + 15,000×0.6 = **11,000**. **방안2**(고정 20,000 + 매출 20% 성과급): 단위당 CM = 2,000 − 1,000 − 400 = 600. 50단위 이익 = 30,000 − 25,000 = 5,000, 60단위 이익 = 36,000 − 25,000 = 11,000. 기대 = 5,000×0.4 + 11,000×0.6 = 8,600. 방안1(11,000) > 방안2(8,600) → 선택 시 기대영업이익 = **11,000**. 함정: 단순히 기대판매량(56단위)에 단위당 CM을 곱하면 안 되며, **각 방안별로 시나리오별 이익을 계산한 뒤 가중평균**해야 한다. 또한 성과급은 **매출액**의 20%이므로 단위당 400(=2,000×20%)이 추가 변동비가 된다.
