<div class='question-block'>
<strong>[문제]</strong> 다음은 제조업을 영위하는 영리내국법인 ㈜한라(중소기업 아님, 사회적기업 아님)의 제25기 사업연도(2025.1.1.~2025.12.31.) 자료이다. 아래 자료를 이용하여 ㈜한라의 제25기 <strong>각사업연도소득금액, 과세표준 및 산출세액</strong>을 계산하시오. 제시된 자료 외의 세무조정 사항은 없으며, 전기까지의 세무조정은 모두 적법하게 이루어졌다.

<br><br>

<strong>1. 손익계산서 관련 자료</strong>
<ul>
<li>손익계산서상 당기순이익: 980,000,000원</li>
<li>손익계산서에 계상된 법인세비용: 120,000,000원</li>
</ul>

<strong>2. 수입금액 자료</strong>
<ul>
<li>기업회계기준상 매출액: 20,000,000,000원</li>
<li>위 매출액 중 특수관계인에 대한 매출액: 2,000,000,000원 (나머지 18,000,000,000원은 일반수입금액)</li>
</ul>

<strong>3. 기업업무추진비 자료</strong>
<ul>
<li>손익계산서상 기업업무추진비 계상액: 95,000,000원 (전액 당기 지출분이며, 적격증명서류 수취 요건을 모두 충족함)</li>
<li>문화 기업업무추진비 및 전통시장 지출분은 없음</li>
</ul>

<strong>4. 감가상각비 자료</strong>
<ul>
<li>기계장치 감가상각비 손익계산서 계상액: 150,000,000원</li>
<li>법인세법상 상각범위액: 120,000,000원</li>
<li>전기 이월 상각부인액 및 시인부족액은 없음</li>
</ul>

<strong>5. 대손충당금 자료</strong>
<ul>
<li>기말 재무상태표상 대손충당금 잔액: 60,000,000원</li>
<li>기말 현재 세법상 대손충당금 설정대상 채권가액: 2,000,000,000원</li>
<li>당기 대손실적률: 1.5%</li>
<li>전기 자본금과 적립금 조정명세서(을)상 대손충당금 한도초과액(유보): 20,000,000원</li>
</ul>

<strong>6. 수입배당금 자료</strong>
<ul>
<li>비상장 내국법인 A사(지분율 30%, 배당기준일 현재 3년 이상 보유)로부터 받은 현금배당 50,000,000원이 영업외수익에 계상되어 있음</li>
<li>㈜한라는 차입금이 없어 지급이자 차감 규정은 적용되지 않음</li>
</ul>

<strong>7. 이월결손금 자료</strong>
<ul>
<li>2021 사업연도 발생분 세무상 이월결손금 잔액: 300,000,000원 (이후 공제된 바 없음)</li>
<li>비과세소득 및 소득공제는 없음</li>
</ul>
</div>

<div class='calc-step'>
  <div class='calc-step-header'>
    <span style='display:flex;align-items:center;flex:1;'>
      <span class='calc-step-num'>1</span>
      <span class='calc-step-title'>1단계 — 기업업무추진비 한도초과액 계산</span>
    </span>
    <span class='calc-step-toggle'>▼</span>
  </div>
  <div class='calc-step-body'>
㈜한라는 중소기업이 아니므로 기본한도는 연 12,000,000원을 적용한다. 수입금액 적용률은 100억원 이하분 0.3%, 100억원 초과 500억원 이하분 0.2%이며, 일반수입금액에 낮은 구간부터 먼저 적용률을 적용한 후 특수관계인 수입금액은 다음 구간의 적용률을 곱한 금액의 10%만 한도에 산입한다.

<pre>
① 기본한도            = 12,000,000 × 12/12        = 12,000,000
② 일반수입금액분
   100억 이하분        = 10,000,000,000 × 0.3%     = 30,000,000
   100억 초과분        =  8,000,000,000 × 0.2%     = 16,000,000
③ 특수관계인 수입금액분 =  2,000,000,000 × 0.2% × 10% =    400,000
─────────────────────────────────────────────
한도액 = 12,000,000 + 30,000,000 + 16,000,000 + 400,000
       = 58,400,000
</pre>

<pre>
한도초과액 = 지출액 95,000,000 − 한도액 58,400,000
           = 36,600,000
</pre>

**중간 답 = 기업업무추진비 한도초과 36,600,000원 (손금불산입, 기타사외유출)**
  </div>
</div>

<div class='calc-step'>
  <div class='calc-step-header'>
    <span style='display:flex;align-items:center;flex:1;'>
      <span class='calc-step-num'>2</span>
      <span class='calc-step-title'>2단계 — 감가상각비·대손충당금·수입배당금 세무조정</span>
    </span>
    <span class='calc-step-toggle'>▼</span>
  </div>
  <div class='calc-step-body'>
<strong>(1) 감가상각비</strong> — 회사계상액이 상각범위액을 초과하므로 초과분을 부인한다.

<pre>
상각부인액 = 150,000,000 − 120,000,000 = 30,000,000
→ 손금불산입 30,000,000 (유보)
</pre>

<strong>(2) 대손충당금</strong> — 한도는 설정대상 채권가액 × Max(1%, 대손실적률)이며, 총액법에 따라 전기 한도초과액(유보)은 당기에 무조건 추인한다.

<pre>
한도액     = 2,000,000,000 × Max(1%, 1.5%) = 30,000,000
한도초과액 = 60,000,000 − 30,000,000       = 30,000,000
→ 손금불산입 30,000,000 (유보)
→ 전기 한도초과액 20,000,000 손금산입 (△유보 추인)
</pre>

<strong>(3) 수입배당금 익금불산입</strong> — 비상장 내국법인 지분율 20% 이상 50% 미만이므로 익금불산입률 80%를 적용한다. 지급이자 차감액은 없다.

<pre>
익금불산입액 = 50,000,000 × 80% = 40,000,000
→ 익금불산입 40,000,000 (기타)
</pre>

**중간 답 = 손금불산입 60,000,000원(유보) / 손금산입 20,000,000원(△유보) / 익금불산입 40,000,000원(기타)**
  </div>
</div>

  <div class='calc-step-header'>
    <span style='display:flex;align-items:center;flex:1;'>
      <span class='calc-step-num'>3</span>
      <span class='calc-step-title'>3단계 — 세무조정 집계 및 각사업연도소득금액 산출</span>
    </span>
    <span class='calc-step-toggle'>▼</span>
  </div>
  <div class='calc-step-body'>
법인세비용은 손금불산입 항목(기타사외유출)임에 유의하여 전체 조정을 집계한다.

<pre>
당기순이익                                      980,000,000
(가산조정)
 + 법인세비용 손금불산입                        120,000,000
 + 기업업무추진비 한도초과                       36,600,000
 + 감가상각비 상각부인액                         30,000,000
 + 대손충당금 한도초과                           30,000,000
                                    소계     + 216,600,000
(차감조정)
 − 전기 대손충당금 한도초과 추인                 20,000,000
 − 수입배당금 익금불산입                         40,000,000
                                    소계      − 60,000,000
─────────────────────────────────────────────
각사업연도소득금액 = 980,000,000 + 216,600,000 − 60,000,000
                  = 1,136,600,000
</pre>

**중간 답 = 각사업연도소득금액 1,136,600,000원**
  </div>
</div>

<div class='calc-step'>
  <div class='calc-step-header'>
    <span style='display:flex;align-items:center;flex:1;'>
      <span class='calc-step-num'>4</span>
      <span class='calc-step-title'>4단계 — 이월결손금 공제와 과세표준 확정</span>
    </span>
    <span class='calc-step-toggle'>▼</span>
  </div>
  <div class='calc-step-body'>
2021년 발생 결손금은 15년의 공제기간 이내이므로 공제 가능하다. 다만 ㈜한라는 중소기업이 아니므로 이월결손금 공제한도는 각사업연도소득금액의 80%가 적용된다.

<pre>
공제한도 = 1,136,600,000 × 80% = 909,280,000
이월결손금 300,000,000 ≤ 909,280,000 → 전액 공제 가능
</pre>

<pre>
과세표준 = 각사업연도소득금액 − 이월결손금 − 비과세소득 − 소득공제
         = 1,136,600,000 − 300,000,000 − 0 − 0
         = 836,600,000
</pre>

**중간 답 = 과세표준 836,600,000원**
  </div>
</div>

      <span class='calc-step-title'>5단계 — 산출세액 계산</span>
    </span>
    <span class='calc-step-toggle'>▼</span>
  </div>
  <div class='calc-step-body'>
2025.1.1. 개시 사업연도이므로 과세표준 2억원 이하 9%, 2억원 초과 200억원 이하 19%의 세율을 적용한다. (2026.1.1. 이후 개시 사업연도부터는 구간별 1%p 인상된 세율(10%·20%·22%·25%)이 적용되므로 문제의 사업연도 개시일을 반드시 확인할 것 <code>[확인 필요]</code>)

<pre>
산출세액 = 200,000,000 × 9% + (836,600,000 − 200,000,000) × 19%
         = 18,000,000 + 636,600,000 × 19%
         = 18,000,000 + 120,954,000
         = 138,954,000
</pre>

**중간 답 = 산출세액 138,954,000원**
