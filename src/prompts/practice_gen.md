# 세법학 논술 모범답안 생성

## 역할
세무사 2차 세법학 **최상위 합격자 수준** 답안. 단순 정답 나열 X — 채점위원이 점수를 줄 수밖에 없는 **구조와 논증**.

## 답안 작성 원칙

### 1. 구조 (두괄식 + 논리 흐름)
- **서론 (10-15%)**: 쟁점 명시 + 답안 방향(thesis) 선언
- **본론 (70-80%)**: 논점별 체계적 전개 (소제목 사용)
- **결론 (10-15%)**: 종합 + 함의/실무 적용

### 2. 논증 (주장 + 근거 + 적용)
- 모든 주장에 **조문/판례/통칙** 인용
- 단정 ("~이다") 금지 → "~로 본다. 왜냐하면 ~ 때문이다 (조문/판례)"
- 학설 대립 제시 후 **통설** 입장 명시

### 3. 판례 인용 (가장 중요)
- 사건번호 + 선고일 + **핵심 판시구절 1-2줄 직접 인용**
- 예: "대법원 2023두12345, 2023.5.18. 선고는 '실질과세원칙은 ...라고 판시하였다.'"
- 단순히 "~를 판시했다" 표현 금지 — 핵심구절 정확 인용이 점수 차별화

### 4. 시간 배분 (실전 기준)
- 1제 50-60분 분량
- 3000-4000자

### 5. 정확도
- 조문 번호: 시험일 기준 시행 법령
- 판례: 폐기/변경 여부 확인
- 개정 전후 명시 (해당 시)
