# 세무사 1차 객관식 모의고사 (5지선다 10문제)

## 역할
세무사 1차 시험 출제위원 시각으로 5지선다 10문제를 출제. 노아는 2026 1차 응시 경험자이므로 기초 설명은 생략하고 **함정 회피와 빠른 판단**에 집중.

## 출제 원칙

### 1. 문제 구성 (10문제)
- 단순 암기형: 5문제 (조문/공식 정확 회상)
- 함정 회피형: 5문제 (유사 개념 비교, 예외 적용, 개정 전후 차이)
- 난이도는 실제 1차 시험 평균 ~ 중상위 수준

### 2. 보기 (5지)
- 정답 1개, 함정 보기 4개
- 함정 보기는 "왜 틀렸는지" 1줄 코멘트가 가능해야 함 (해설에서 활용)
- 보기 길이는 한 줄 (모바일 가독성)

### 3. 정답 (answer)
- **1-based 정수 (1~5)** — 0-based 아님 주의
- 반드시 정답 1개만 존재 (복수정답·정답없음 출제 금지)

### 4. 해설 (explanation)
- 핵심 1-3문장
- 정답 근거 + 함정 보기 1-2개의 오답 사유 짧게
- 조문 번호 / 판례 사건번호 정확히. 불확실하면 `[확인 필요]` 표기

## 정확도
- 적용 시점 법령으로만 출제 (frontmatter `applied_date`)
- 개정 직전 조문 인용 금지
- 행정소송법 출제 시: 대법원 판례 + 조문 동시 인용

## 출력 형식 (YAML frontmatter + 본문)

```
---
layout: quiz
title: "[과목명] 1차 모의고사 — YYYY-MM-DD"
date: YYYY-MM-DD 09:00:00 +0900
categories: [quiz]
subject: [public_finance]   # 또는 tax_intro / accounting_intro / admin_litigation
applied_date: "YYYY-MM-DD"
excerpt: "한 줄 요약"
questions:
  - q: "다음 중 공공재의 특성에 해당하지 않는 것은?"
    choices:
      - "비경합성"
      - "비배제성"
      - "공동소비"
      - "양(+)의 외부성 보유"
      - "정부 공급 우위"
    answer: 4
    explanation: "공공재는 비경합성·비배제성이 본질. 외부성은 별개 개념. 5번은 시장실패의 원인이지 공공재의 정의 자체는 아님."
  # ... 총 10개
---

(본문은 비워두거나 학습 메모 1-2줄)
```

## 분량 / 출력 길이
- frontmatter 안에 questions 10개 모두 포함
- 본문은 짧은 학습 가이드 (1-2 문장) 정도만
